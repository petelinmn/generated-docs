# Generated Docs — база знаний

🌐 **Русский** · [English](README.en.md)

Учебные материалы по технологиям, сгенерированные Claude по единым правилам и проверенные на практике. Каждая тема описана на русском и английском и генерируется до нужного уровня детализации: от базовой теории до запускаемых примеров с тестами.

## Уровни детализации

У каждой темы всегда есть `overview` — краткая версия и карта уровней. Дальше тема генерируется до нужного уровня:

| Уровень | Что | Файлы |
|---|---|---|
| 1 | Базовая теория | `basics.ru.md`, `basics.en.md` |
| 2 | Продвинутая теория | `advanced.ru.md`, `advanced.en.md` |
| 3 | Экспертная теория: почти полный справочник по теме, подвохи, вопросы с собеседований с ответами | `expert.ru.md`, `expert.en.md` |
| 4 | Самопроверка: квиз и упражнения | `quiz.*.md`, `exercises.*.md` |
| 5 | Запускаемые примеры — для нетривиального | `code/examples/`, `code/solutions/` |
| 6 | Тесты — для важного | `code/tests/` |

- На уровнях 1–4 код только внутри md, но перед публикацией он проверяется запуском.
- `level N` — все уровни до N включительно; можно перечислить отдельные уровни: `levels 1,4`.
- Уровень по умолчанию задан для каждого трека: C# — 6 (исчерпывающе, с тестами), остальные — 4.
- Уровень можно поднять в любой момент: недостающие уровни добавятся, существующие файлы не перепишутся.

## Структура

```text
generated-docs/
├── README.md               выбор языка
├── README.ru.md / .en.md   ты здесь
├── PROGRESS.md             прогресс изучения (чекбоксы)
├── PLAN.md                 порядок изучения, этапы, бэклог
├── CLAUDE.md               правила генерации (Claude читает автоматически)
├── _templates/             шаблоны документов
├── tools/check-docs.ps1    автопроверка документации
├── .claude/skills/         команды /learn, /quiz-me, /verify
└── tracks/<track>/
    ├── overview.ru.md / .en.md   кратко о технологии + дорожная карта
    ├── modules/NN-slug/          темы по порядку изучения
    ├── libraries/<name>/         библиотеки (в kubernetes и linux — tools/)
    ├── recipes/<feature>/        «как реализовать фичу X»
    ├── projects/<name>/          ТЗ итоговых проектов + твоё решение в src/
    └── review.md                 ошибки из /quiz-me для повторения
```

## Как работать

1. `/learn python 14 level 2` или `/learn csharp` (уровень по умолчанию трека) — Claude генерирует материал (`status: draft`).
2. Читаешь `overview`, затем `basics`, `advanced`, `expert` — сколько нужно.
3. Если есть `code/`: запускаешь примеры и тесты, меняешь код и смотришь, что ломается.
4. Проходишь `quiz` или `/quiz-me python/14-asyncio` — интерактивный квиз в чате. Решаешь `exercises`.
5. Нужно глубже — `/learn python 14 level 4`: добавятся экспертная теория и самопроверка.
6. `/verify tracks/python/modules/14-asyncio` — независимая проверка → `verified`.
7. Отмечаешь `[x]` в [PROGRESS.md](PROGRESS.md).

## Команды

| Команда | Что делает |
|---|---|
| `/learn <тема> [level N]` | документация по любой теме до уровня N, или повышение уровня существующей |
| `/quiz-me <track>/<модуль>` | интерактивный квиз: вопросы по одному, разбор ошибок |
| `/verify <путь>` | факты, тесты, перевод, ссылки → `verified` |
| `powershell -NoProfile -ExecutionPolicy Bypass -File tools/check-docs.ps1 [путь]` | автопроверка: пары ru/en, структура, front matter, битые ссылки |
