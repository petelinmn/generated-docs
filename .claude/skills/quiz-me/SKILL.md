Проведи интерактивный квиз. Аргументы: $ARGUMENTS

1. **Материал.** Найди файлы теории материала: `basics.ru.md`, `advanced.ru.md`, `expert.ru.md` — какие есть (см. `levels` в overview) — и `quiz.ru.md`, если он есть. Если указан только трек, возьми модули, отмеченные `[x]` в `PROGRESS.md`. Если у трека есть `review.md`, добавь 1–2 вопроса оттуда на повторение. Если теории нет, задавай вопросы по теме в целом и предупреди, что они не опираются на проверенный материал.
2. **Язык** — русский. Если в аргументах есть `en` или пользователь просит английский, квиз идёт на английском по `.en.md`-версиям.
3. **Вопросы** придумывай новые, не копируя `quiz.*.md`: пользователь мог их уже видеть. Опирайся только на текст существующих уровней теории. По умолчанию 7 вопросов, сложность растёт: базовая → продвинутая → экспертная. Если указан уровень (1, 2 или 3), задавай вопросы только по нему. Чередуй типы: выбор ответа, «что выведет код», «найди ошибку», «объясни своими словами», а на уровне 3 — вопросы с собеседований и с подвохом.
4. **Задавай строго по одному вопросу** и жди ответа. Не подсказывай и не показывай ответ заранее. Для вопросов с вариантами можно использовать AskUserQuestion.
5. **После каждого ответа:** вердикт (верно / частично / неверно), короткое объяснение и ссылка на нужный файл уровня.
6. **В конце:** счёт N/M, слабые места по уровням, что перечитать.
7. **Ошибки:** вопросы с неверным или частичным ответом допиши в конец `tracks/<track>/review.md` (создай файл, если его нет):

   ```markdown
   ### YYYY-MM-DD · <модуль> · <уровень>
   **Вопрос:** …
   **Мой ответ:** …
   **Правильно:** … → [advanced](modules/NN-slug/advanced.ru.md#раздел)
   ```

   Существующие записи в `review.md` не меняй и не удаляй.
