# Подготовка окружения: квиз

🌐 **Русский** · [English](quiz.en.md)

> Сначала ответьте сами, затем раскройте ответ. 🟢 [базовый](basics.ru.md) · 🟡 [продвинутый](advanced.ru.md) · 🔴 [экспертный](expert.ru.md).

## 1. 🟢 Чем WSL 2 отличается от WSL 1 прежде всего?

- A) WSL 2 работает без виртуализации
- B) WSL 2 — это контейнер Docker
- C) WSL 2 запускает настоящее ядро Linux в лёгкой виртуальной машине
- D) WSL 2 переводит системные вызовы Linux в вызовы Windows

<details><summary>Ответ</summary>

**C.** Настоящее ядро даёт полную совместимость системных вызовов и systemd. Перевод вызовов — это подход WSL 1. Виртуализация WSL 2 как раз нужна, а Docker — отдельный продукт.
→ [Базовая теория](basics.ru.md)

</details>

## 2. 🟢 Что делает `wsl --unregister Ubuntu`?

- A) Безвозвратно удаляет дистрибутив и все его данные
- B) Останавливает дистрибутив
- C) Убирает его из дистрибутивов по умолчанию, файлы остаются
- D) Делает резервную копию и удаляет

<details><summary>Ответ</summary>

**A.** Данные, настройки и программы теряются. Остановка — `--terminate`; копию нужно сделать самому через `--export`.
→ [Базовая теория](basics.ru.md)

</details>

## 3. 🟢 Где выше скорость для инструментов Linux?

- A) В `/mnt/c/Users/me/project`
- B) Разницы нет
- C) Только на `/mnt/d`
- D) В `~/project` внутри файловой системы Linux

<details><summary>Ответ</summary>

**D.** Доступ к смонтированному диску Windows идёт через границу двух ОС и заметно медленнее. Буква диска ничего не меняет.
→ [Базовая теория](basics.ru.md)

</details>

## 4. 🟢 Чем различаются `uname -r` и `/etc/os-release`?

- A) Второе — версия WSL
- B) Первое — версия ядра, второе — описание дистрибутива
- C) Это два способа узнать одну версию
- D) Первое — версия bash

<details><summary>Ответ</summary>

**B.** В контейнере это особенно видно: дистрибутив берётся из образа, а ядро — общее с хостом.
→ [Базовая теория](basics.ru.md)

</details>

## 5. 🟢 Что означает `#` в конце приглашения?

- A) Это режим только для чтения
- B) Shell запущен от root
- C) Команда закомментирована
- D) Идёт фоновая задача

<details><summary>Ответ</summary>

**B.** По соглашению `$` — обычный пользователь, `#` — root. Комментарием `#` служит только внутри набранной строки.
→ [Базовая теория](basics.ru.md)

</details>

## 6. 🟡 Вы изменили `/etc/wsl.conf`. Что нужно сделать?

- A) Выполнить `source /etc/wsl.conf`
- B) Ничего, файл читается при каждой команде
- C) Перезагрузить только bash командой `exec bash`
- D) Остановить дистрибутив (`wsl --terminate`) и запустить снова

<details><summary>Ответ</summary>

**D.** Настройки читаются при запуске дистрибутива. Это не shell-скрипт, и перезапуск bash дистрибутив не перезапускает.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 7. 🟡 Где задать лимит памяти для виртуальной машины WSL 2?

- A) В `%UserProfile%\.wslconfig`
- B) В `/etc/wsl.conf`
- C) В `~/.bashrc`
- D) В `/etc/os-release`

<details><summary>Ответ</summary>

**A.** Память относится ко всей VM, общей для дистрибутивов, поэтому настройка глобальная. `wsl.conf` действует на один дистрибутив.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 8. 🟡 Выберите верные утверждения про `chmod` на `/mnt/c` без опции `metadata`.

- [ ] A) `chmod 600` скрывает файл от других пользователей Windows
- [ ] B) Файловая система становится только для чтения
- [ ] C) Режим Linux не сохраняется
- [ ] D) Снятие всех битов записи ставит атрибут Windows «только чтение»

<details><summary>Ответ</summary>

**C, D.** Права на таком диске выводятся из прав Windows. На доступ других пользователей Windows `chmod` не влияет.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 9. 🟡 Скрипт с CRLF запускается с ошибкой `required file not found` (или `bad interpreter`). Почему?

- A) У файла нет права на выполнение
- B) bash не установлен
- C) Скрипт нужно запускать через `sudo`
- D) В первой строке интерпретатором считается `/bin/bash\r`, а такого файла нет

<details><summary>Ответ</summary>

**D.** `\r` — обычный символ для Linux. Без права на выполнение сообщение было бы `Permission denied`.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 10. 🟡 Что верно про Ubuntu 26.04 по умолчанию?

- A) bash заменён на shell на Rust
- B) Многие базовые утилиты — из uutils, а `sudo` — это sudo-rs
- C) Все утилиты по-прежнему из GNU
- D) `cp`, `mv`, `rm` тоже из uutils

<details><summary>Ответ</summary>

**B.** `cp`, `mv`, `rm` в 26.04 оставлены от GNU. Shell остался bash.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 11. 🔴 Открытый вопрос: вы хотите опробовать команду, которая может испортить систему. Как построите эксперимент?

<details><summary>Ответ</summary>

Ключевые пункты: одноразовая среда (контейнер с `--rm` или импортированная копия дистрибутива); не монтировать в неё рабочие каталоги и помнить, что в WSL диски Windows доступны через `/mnt`; заранее знать, как всё откатить; сначала посмотреть, что именно затронет команда (`echo` перед раскрытием шаблонов).
→ [Базовая теория](basics.ru.md)

</details>
