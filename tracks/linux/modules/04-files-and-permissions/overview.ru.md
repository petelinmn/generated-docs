# Файлы и права

🌐 **Русский** · [English](overview.en.md)

## Коротко

У каждого файла есть владелец, группа и биты прав. Они решают, кто может читать, менять и запускать его. Модуль объясняет, как их читать и менять, почему каталоги ведут себя иначе, что такое специальные биты и как ACL расширяют модель.

## Ключевые идеи

- Три класса: владелец, группа, остальные. К пользователю применяется только один.
- У каталога `r` перечисляет имена, `w` создаёт и удаляет их, `x` позволяет проходить внутрь.
- Для удаления файла нужны права на каталог, а не на файл.
- `umask` убирает биты у новых файлов.
- Биты setgid и sticky делают общие каталоги рабочими.
- ACL дают права дополнительным пользователям и группам.

## Минимальный пример

```bash
touch script.sh
stat -c '%A %a %n' script.sh
chmod u+x script.sh
stat -c '%A %a %n' script.sh
```

```text
-rw-r--r-- 644 script.sh
-rwxr--r-- 744 script.sh
```

## Когда применять и когда нет

- ✅ Владелец, группа и режим — почти для всего.
- ✅ Каталог с setgid — для работы команды; ACL — для одного дополнительного пользователя.
- ❌ `chmod 777`, «чтобы заработало».
- ❌ Свои setuid-программы без очень веской причины.
