# Объекты и прототипы

🌐 **Русский** · [English](overview.en.md)

## Коротко

Объект в JavaScript — набор пар «ключ — значение» (свойств). Ключи — строки или символы, значения — любые. Создавать объекты проще всего **литералом** `{ a: 1 }`. У каждого объекта есть **прототип** — другой объект, к которому JavaScript обращается, если свойство не найдено у самого объекта. Цепочка прототипов — основа наследования в языке. У свойств есть **атрибуты** (записываемость, перечисляемость, настраиваемость), а объект можно заморозить. Копии объектов по умолчанию **поверхностные**: вложенные объекты остаются общими. Для разбора объектов и массивов есть **деструктуризация** и оператор распространения `...`.

## Ключевые идеи

- **Литерал — основной способ:** сокращённая запись `{ x, y }`, вычисляемые ключи `[expr]`, методы, геттеры и сеттеры.
- **Ключи — строки (или символы):** `o[1]` и `o['1']` — одно и то же свойство; порядок ключей определён (целочисленные по возрастанию, затем строки по порядку добавления).
- **`in` проверяет и цепочку прототипов,** а `Object.hasOwn(o, k)` — только собственные свойства.
- **Прототип — запасной источник свойств:** чтение идёт по цепочке, а запись создаёт собственное свойство у объекта.
- **`Object.keys`, `values`, `entries` перечисляют только собственные перечисляемые свойства;** `for...in` захватывает и унаследованные.
- **Копирование `{ ...o }` и `Object.assign` поверхностное;** для глубокой копии — `structuredClone`.
- **`Object.freeze` защищает от записи только верхний уровень** (в строгом режиме нарушение — `TypeError`).
- **Деструктуризация** достаёт поля и элементы по шаблону, поддерживает значения по умолчанию и остаток `...rest`.

## Минимальный пример

```js
const proto = { hello() { return 'hi ' + this.name; } };
const child = Object.create(proto);
child.name = 'c';
const { name, ...rest } = { name: 'x', a: 1, b: 2 };
console.log(child.hello(), Object.keys(child), name, rest);
```

```text
hi c [ 'name' ] x { a: 1, b: 2 }
```

## Когда применять, а когда нет

| Задача | Инструмент |
|---|---|
| Записать данные как набор полей | литерал `{ ... }` |
| Словарь с произвольными ключами | `Map` (модуль 07 дорожной карты) или объект без прототипа `Object.create(null)` |
| Поверхностная копия | `{ ...o }` |
| Глубокая копия | `structuredClone(o)` |
| Запретить изменения | `Object.freeze` (поверхностно) |
| Наследование «по цепочке» | `Object.create(proto)`, сегодня чаще `class` (модуль 06) |

- ❌ Не используйте обычный объект как словарь для ключей из ввода пользователя без защиты (ключи вроде `__proto__`).
- ❌ Не считайте `{ ...o }` глубокой копией.
