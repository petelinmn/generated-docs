# Итераторы и генераторы

🌐 **Русский** · [English](overview.en.md)

## Коротко

Протокол итерации — договорённость, по которой `for...of`, spread, деструктуризация, `Map`, `Set` и `Array.from` перебирают значения. Итерируемый объект (iterable) умеет создать итератор (iterator), а тот отдаёт значения по одному через `next()`. Генератор (`function*`) — самый простой способ написать итератор: функция, которую можно приостановить на `yield`. Асинхронные версии (`for await`, `async function*`) перебирают значения, которые приходят со временем.

## Ключевые идеи

- **Итерируемый объект** имеет метод `[Symbol.iterator]()`, возвращающий итератор.
- **Итератор** имеет `next()`, возвращающий `{ value, done }`.
- **`for...of`, spread, деструктуризация** работают с любым итерируемым объектом; обычный объект `{}` не итерируем.
- **Генератор** приостанавливается на `yield` и возобновляется по `next()`; он ленив и может быть бесконечным.
- **`next(x)` передаёт значение внутрь** генератора как результат `yield`.
- **`return()` и `throw()`** завершают генератор или бросают в него исключение; `finally` при этом выполняется.
- **Досрочный выход из `for...of`** вызывает `return()` итератора: ресурсы освобождаются.
- **Хелперы итераторов** (`map`, `filter`, `take`, `drop`, `toArray`, …) работают лениво прямо на итераторах.
- **Асинхронные итераторы** (`Symbol.asyncIterator`, `async function*`, `for await`) перебирают данные по мере поступления.

## Минимальный пример

```js
function* nat() { let n = 0; while (true) yield n++; }
console.log(nat().filter(x => x % 2).map(x => x * x).take(4).toArray());
```

```text
[ 1, 9, 25, 49 ]
```

Бесконечная последовательность обрабатывается лениво: вычисляется только то, что нужно для четырёх результатов.

## Когда применять и когда нет

| Задача | Выбор |
|---|---|
| Свой тип, по которому можно делать `for...of` | `[Symbol.iterator]` (часто генератор) |
| Ленивая или бесконечная последовательность | генератор |
| Постраничная загрузка, поток событий | асинхронный генератор + `for await` |
| Простое преобразование готового массива | методы массива ([модуль 07](../07-arrays-and-collections/overview.ru.md)) |
| Параллельные запросы | промисы ([модуль 12](../12-promises-and-async-await/overview.ru.md)), не `for await` |

- ❌ Не используйте генераторы там, где хватает массива: накладные расходы без пользы.
- ❌ Не ждите, что `for await` выполнит шаги параллельно: он последовательный.
