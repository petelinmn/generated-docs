# Строки, числа, даты, регулярные выражения

🌐 **Русский** · [English](overview.en.md)

## Коротко

Тема объединяет четыре повседневных инструмента. **Строки** неизменяемы, хранятся как последовательность 16-битных кодовых единиц UTF-16 и имеют богатый набор методов. **Числа** — это 64-битные числа с плавающей точкой: для форматирования есть `toFixed`, `toString(основание)` и `Intl.NumberFormat`, для вычислений — объект `Math`. **Даты** (`Date`) — число миллисекунд от 1 января 1970 года (UTC) с неудобным API и ловушками часовых поясов. **Регулярные выражения** (`RegExp`) ищут и заменяют текст по шаблону. Для локализации (форматы чисел, дат, списков, множественное число) используется встроенный `Intl`.

## Ключевые идеи

- **Строки неизменяемы;** методы возвращают новые. `length` считает кодовые единицы UTF-16, а не символы.
- **Для сравнения с учётом языка** используйте `localeCompare` или `Intl.Collator`, а не `<` и `>`.
- **`toFixed` возвращает строку и страдает от двоичной точности:** `(1.005).toFixed(2)` — `'1.00'`.
- **`Intl` форматирует числа, даты и списки по правилам языка** без сторонних библиотек.
- **`Date` — миллисекунды от начала эпохи в UTC;** месяцы нумеруются с нуля, а строка `'2024-01-15'` (без времени) разбирается как UTC, а `new Date(2024, 0, 15)` — как местное время.
- **Выход за диапазон «переливается»:** `new Date(2024, 1, 0)` — последний день января.
- **У регулярных выражений есть флаги:** `g` (все совпадения), `i` (регистр), `m`, `s`, `u` (Юникод), `y`, `d`; группы бывают пронумерованными и именованными.
- **Флаг `g` делает `RegExp` состоянием:** `lastIndex` сохраняется между вызовами `test`.
- **Жадные квантификаторы и вложенные повторы могут «взорвать» время** (ReDoS).

## Минимальный пример

```js
console.log('Hello'.padStart(8, '*'), (1234.5678).toFixed(2), new Intl.NumberFormat('en-US').format(1234567.891));
console.log(new Date(Date.UTC(2024, 0, 31)).toISOString(), '2024-05-17'.match(/(?<y>\d{4})-(?<m>\d{2})/).groups.y);
```

```text
***Hello 1234.57 1,234,567.891
2024-01-31T00:00:00.000Z 2024
```

## Когда применять, а когда нет

| Задача | Инструмент |
|---|---|
| Форматирование чисел и валют | `Intl.NumberFormat` |
| Форматирование дат | `Intl.DateTimeFormat`, `toLocaleDateString` |
| Хранение момента времени | `Date.now()` или ISO-строка в UTC |
| Сложные операции с календарём и часовыми поясами | специализированная библиотека (Temporal в этой среде отсутствует) |
| Простой поиск подстроки | `includes`, `indexOf`, `startsWith` |
| Шаблонный поиск и замена | `RegExp` |
| Разбор структурированных данных (HTML, JSON) | парсер, а не регулярное выражение |

- ❌ Не пишите деньги в `float`: считайте в минимальных единицах (копейки).
- ❌ Не разбирайте HTML регулярными выражениями.
