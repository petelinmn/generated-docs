# Классы

🌐 **Русский** · [English](overview.en.md)

## Коротко

Синтаксис `class` — удобная запись для конструкторов и прототипов ([модуль 04](../04-functions/overview.ru.md), [модуль 05](../05-objects-and-prototypes/overview.ru.md)). Класс описывает конструктор, методы (они лежат на прототипе), геттеры и сеттеры, статические члены и поля экземпляра. Приватные члены записываются с `#` и недоступны снаружи. Наследование — `extends`, обращение к родителю — `super`. Под капотом по-прежнему прототипы: `typeof Point` равен `'function'`. В отличие от функции-конструктора, класс нельзя вызвать без `new`, а тело его методов работает в строгом режиме.

## Ключевые идеи

- **`class`** — функция-конструктор с прототипом; вызов без `new` — `TypeError`.
- **Методы лежат на прототипе и неперечисляемы;** поля экземпляра создаются в самом объекте.
- **Геттеры и сеттеры** определяют вычисляемые свойства; **статические члены** принадлежат классу, а не экземпляру.
- **Приватные члены `#x`** доступны только внутри тела класса; снаружи — синтаксическая ошибка, а не `undefined`.
- **`extends` и `super`:** в конструкторе наследника нужно вызвать `super(...)` до обращения к `this`.
- **Класс не всплывает как функция:** до объявления он в TDZ ([модуль 03](../03-scopes-and-hoisting/overview.ru.md)).
- **Поля инициализируются после `super()`:** метод, вызванный из конструктора родителя, не увидит поля наследника.
- **Метод теряет `this` при передаче как значения;** помогает поле со стрелкой или `bind`.
- **Классы можно расширять встроенные (`Array`, `Error`)** и собирать «примеси» (mixins) функциями.

## Минимальный пример

```js
class Point {
  #secret = 42;
  constructor(x, y) { this.x = x; this.y = y; }
  get len() { return Math.hypot(this.x, this.y); }
  reveal() { return this.#secret; }
  toString() { return `(${this.x}, ${this.y})`; }
}
const p = new Point(3, 4);
console.log(p.len, `${p}`, p.reveal(), Object.keys(p));
```

```text
5 (3, 4) 42 [ 'x', 'y' ]
```

`#secret` не попадает в `Object.keys`, а `len` — геттер на прототипе.

## Когда применять, а когда нет

| Задача | Выбор |
|---|---|
| Много объектов одного вида с поведением | `class` |
| Единичный объект с данными | литерал `{ ... }` ([модуль 05](../05-objects-and-prototypes/overview.ru.md)) |
| Простая фабрика с замыканием | функция ([модуль 04](../04-functions/overview.ru.md)) |
| Типизированная структура данных | `class` или `interface` в [TypeScript](../../../typescript/overview.ru.md) |
| Расширение поведения без наследования | примесь (mixin) или композиция |

- ❌ Не стройте глубокие иерархии наследования: предпочитайте композицию.
- ❌ Не вызывайте переопределяемые методы из конструктора родителя.
