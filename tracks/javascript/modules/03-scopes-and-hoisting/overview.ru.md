# Переменные и области видимости

🌐 **Русский** · [English](overview.en.md)

## Коротко

Переменные в JavaScript объявляются тремя способами: `const` (нельзя переприсвоить), `let` (можно) и устаревший `var`. Они различаются **областью видимости**: `let` и `const` живут в пределах блока `{ … }`, а `var` — в пределах всей функции. Объявления **«всплывают» (hoisting)**: движок знает о переменной ещё до выполнения строки с объявлением. У `var` до присваивания значение `undefined`, а у `let`/`const` и классов — **временная мёртвая зона (TDZ)**: обращение до объявления вызывает `ReferenceError`. Из-за разницы областей классическая ловушка — замыкания в цикле с `var`.

## Ключевые идеи

- **По умолчанию используйте `const`,** `let` — когда значение нужно менять, `var` — не используйте.
- **`const` запрещает переприсваивание, а не изменение содержимого:** массив и объект, объявленные через `const`, можно менять.
- **Блочная область:** переменные `let`/`const` не видны за пределами `{ }`; `var` «протекает» из блока и цикла.
- **Всплытие:** `var` и объявления функций (`function f() {}`) доступны с начала области; `var` содержит `undefined` до присваивания.
- **TDZ:** `let`, `const` и `class` существуют с начала блока, но обращаться к ним до объявления нельзя.
- **Затенение (shadowing):** внутренняя переменная с тем же именем скрывает внешнюю.
- **Цепочка областей (scope chain):** поиск имени идёт изнутри наружу; это основа замыканий.
- **Переменные верхнего уровня файла-модуля не становятся глобальными:** это переменные модуля.

## Минимальный пример

```js
const fv = [];
for (var a = 0; a < 3; a++) fv.push(() => a);
const fl = [];
for (let b = 0; b < 3; b++) fl.push(() => b);
console.log(fv.map(f => f()), fl.map(f => f()));
```

```text
[ 3, 3, 3 ] [ 0, 1, 2 ]
```

У `var` одна переменная на весь цикл, у `let` — новая на каждой итерации.

## Когда применять, а когда нет

| Задача | Выбор |
|---|---|
| Значение не меняется | `const` |
| Счётчик, накопитель | `let` |
| Нужна переменная в старом коде без блоков | `var` — только при поддержке старого кода |
| Скрыть внутренние данные | функция и замыкание ([модуль 10](../../overview.ru.md) дорожной карты) |

- ❌ Не полагайтесь на всплытие `var`: читайте и объявляйте переменную до использования.
- ❌ Не считайте `const` «неизменяемым значением»: для этого нужна `Object.freeze` (и она поверхностная).
