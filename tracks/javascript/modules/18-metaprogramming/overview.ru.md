# Метапрограммирование

🌐 **Русский** · [English](overview.en.md)

## Коротко

Метапрограммирование — это код, который управляет поведением самого языка и других объектов: перехватывает чтение и запись свойств (`Proxy`), вызывает «внутренние» операции (`Reflect`), настраивает преобразования и итерацию через символы (`Symbol`), разбирает шаблонные строки (теговые шаблоны) и работает со слабыми ссылками (`WeakRef`). Это мощные инструменты для библиотек и фреймворков; в прикладном коде их используют редко и осторожно.

## Ключевые идеи

- **`Proxy` оборачивает объект и перехватывает операции** (`get`, `set`, `has`, `deleteProperty`, `apply`, `construct`, …) через ловушки (traps).
- **`Reflect` — «обычные» версии тех же операций;** ловушка обычно выполняет действие через `Reflect.*`.
- **Прокси соблюдает инварианты:** нельзя «соврать» о неизменяемом свойстве.
- **`Symbol` — уникальный ключ,** не попадающий в `Object.keys` и `JSON.stringify`.
- **Известные символы** (`Symbol.iterator`, `Symbol.toPrimitive`, `Symbol.toStringTag`, `Symbol.hasInstance`, …) настраивают встроенное поведение.
- **Теговый шаблон** получает строки и значения отдельно: основа безопасных шаблонизаторов и `String.raw`.
- **Дескрипторы свойств** (`defineProperty`) задают `writable`, `enumerable`, `configurable`, геттеры и сеттеры.
- **`WeakRef` и `WeakMap` не мешают сборке мусора,** но поведение сборщика недетерминировано.
- **Прокси не равен цели** и ломает методы со слотами (`Map`, приватные поля).

## Минимальный пример

```js
const p = new Proxy({ a: 1 }, {
  get(t, k, r) { console.log('get', String(k)); return Reflect.get(t, k, r); },
});
console.log(p.a);
```

```text
get a
1
```

Чтение свойства прошло через ловушку `get`.

## Когда применять и когда нет

| Задача | Выбор |
|---|---|
| Проверка значений при записи, реактивность | `Proxy` с ловушкой `set` |
| Ленивые или вычисляемые свойства | геттеры, `Proxy` |
| Сделать объект итерируемым или управлять приведением | `Symbol.iterator`, `Symbol.toPrimitive` |
| Безопасная подстановка значений в шаблон | теговый шаблон |
| Скрытые «служебные» ключи | `Symbol` |
| Кэш, не удерживающий объекты | `WeakMap`, `WeakRef` |
| Обычная валидация в приложении | функции и классы, без прокси |

- ❌ Не используйте `Proxy` там, где хватит обычной функции: он замедляет доступ и усложняет отладку.
- ❌ Не полагайтесь на момент сборки мусора и срабатывание `FinalizationRegistry`.
