# Замыкания и функциональный стиль

🌐 **Русский** · [English](overview.en.md)

## Коротко

Замыкание (closure) — функция вместе с переменными внешних областей, которые она «помнит». Благодаря ему функции создают функции с собственным скрытым состоянием: счётчики, фабрики, кэши. Функциональный стиль строится на этом: функции высшего порядка (higher-order functions), каррирование (currying), композиция (composition), чистые функции и неизменяемые данные (immutability).

## Ключевые идеи

- **Замыкание хранит ссылку на переменную, а не её значение:** изменения видны.
- **Каждый вызов фабрики создаёт своё окружение,** поэтому два счётчика не мешают друг другу.
- **Замыкания — способ приватного состояния** без классов.
- **Функция высшего порядка** принимает или возвращает функцию (`map`, `filter`, `reduce`, `bind`).
- **Каррирование и частичное применение** фиксируют часть аргументов; `fn.length` — число параметров до первого значения по умолчанию и rest.
- **Композиция** (`pipe`, `compose`) собирает функции в конвейер.
- **Мемоизация** кэширует результат чистой функции; для объектов-ключей нужна осторожность.
- **`Object.freeze` неглубокий;** для копий — spread, `structuredClone`, `toSorted`/`with`.
- **Рекурсия ограничена стеком;** вместо неё — цикл или trampoline.

## Минимальный пример

```js
function makeCounter() { let n = 0; return { inc: () => ++n, get: () => n }; }
const c1 = makeCounter(), c2 = makeCounter();
c1.inc(); c1.inc(); c2.inc();
console.log(c1.get(), c2.get());
```

```text
2 1
```

У каждого вызова `makeCounter` своя переменная `n`.

## Когда применять и когда нет

| Задача | Выбор |
|---|---|
| Приватное состояние без класса | замыкание |
| Настройка функции «заранее» | частичное применение, `bind` |
| Цепочка преобразований | `pipe`/`compose`, цепочки `map`/`filter` |
| Дорогая чистая функция | мемоизация |
| Общее состояние объекта с методами | класс ([модуль 06](../06-classes/overview.ru.md)) |

- ❌ Не мемоизируйте функции с побочными эффектами и зависимостью от времени.
- ❌ Не считайте `Object.freeze` глубоким.
