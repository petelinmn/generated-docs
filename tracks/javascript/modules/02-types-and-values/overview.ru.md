# Типы и значения

🌐 **Русский** · [English](overview.en.md)

## Коротко

В JavaScript у **значений** есть тип, а у переменных — нет: одна и та же переменная может хранить число, затем строку. Типов семь **примитивных** (`number`, `string`, `boolean`, `undefined`, `null`, `bigint`, `symbol`) и один составной — **объект** (к нему относятся массивы, функции, даты). Примитивы неизменяемы и копируются по значению, объекты передаются по ссылке. Язык охотно приводит типы сам (`'5' + 3` даёт `'53'`, а `'5' - 3` — `2`), поэтому нужно знать правила приведения и всегда предпочитать строгое сравнение `===`.

## Ключевые идеи

- **`typeof` возвращает строку с названием типа,** но с известными исключениями: `typeof null` равен `'object'`, а `typeof` функции — `'function'`.
- **Все числа — 64-битные вещественные (IEEE 754):** `0.1 + 0.2 !== 0.3`, целые точны только до `Number.MAX_SAFE_INTEGER`, есть `NaN`, `Infinity` и `-0`. Для больших целых есть `BigInt`.
- **`NaN` не равен самому себе;** проверяйте `Number.isNaN`, а не глобальную `isNaN`.
- **Строки неизменяемы** и состоят из 16-битных кодовых единиц: эмодзи занимает две.
- **`undefined` — «значения нет», `null` — «значение намеренно пусто».**
- **`==` приводит типы, `===` — нет:** используйте `===`, а `== null` оставьте для проверки на `null` и `undefined` сразу.
- **Ложные значения (falsy): `false`, `0`, `-0`, `0n`, `''`, `null`, `undefined`, `NaN`.** Всё остальное истинно, в том числе `'0'`, `[]` и `{}`.
- **`??` подставляет значение только при `null`/`undefined`,** а `||` — при любом ложном; `?.` безопасно обращается к свойствам.

## Минимальный пример

```js
console.log(typeof 42, typeof 'a', typeof null, typeof undefined);
console.log(0.1 + 0.2, '5' + 3, '5' - 3, 0 || 3000, 0 ?? 3000);
```

```text
number string object undefined
0.30000000000000004 53 2 3000 0
```

## Когда применять, а когда нет

| Задача | Инструмент |
|---|---|
| Строгое сравнение | `===`, `!==` |
| Проверка на `NaN` | `Number.isNaN(x)` |
| Значение по умолчанию только для `null`/`undefined` | `x ?? значение` |
| Точная арифметика с большими целыми | `BigInt` |
| Деньги и точные десятичные доли | целые минимальные единицы (копейки) |
| Копия объекта, а не ссылка | модуль 05 дорожной карты ([объекты и прототипы](../../overview.ru.md)) |

- ❌ Не используйте `==`, кроме проверки `x == null`.
- ❌ Не считайте `typeof x === 'object'` проверкой «это объект»: сюда попадает `null` (и массивы).
