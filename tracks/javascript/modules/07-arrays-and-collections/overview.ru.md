# Массивы и коллекции

🌐 **Русский** · [English](overview.en.md)

## Коротко

Массив (`Array`) — упорядоченный список значений с индексами `0, 1, 2…` и свойством `length`. У него богатый набор методов: `map`, `filter`, `reduce`, `find`, `sort` и другие. Часть методов **меняет** массив на месте (`sort`, `reverse`, `splice`), а новые «копирующие» (`toSorted`, `toReversed`, `with`, `toSpliced`) возвращают копию. Кроме массивов есть **коллекции**: `Set` (уникальные значения), `Map` (ключи любого типа с сохранением порядка вставки), слабые `WeakMap` и `WeakSet`, а для бинарных данных — типизированные массивы (`Uint8Array` и другие). Массив в JavaScript — это объект, поэтому в нём бывают «дырки», а `typeof []` — `'object'`.

## Ключевые идеи

- **Создавайте массивы литералом `[...]`;** `Array(3)` создаёт три пустых слота («дырки»), а не три `undefined`.
- **`length` можно менять:** уменьшение обрезает массив, запись за концом оставляет дырки.
- **Различайте изменяющие методы и копирующие:** `sort()` меняет массив, `toSorted()` — нет.
- **`sort()` без функции сравнения сортирует как строки:** `[10, 9, 1].sort()` — `[1, 10, 9]`.
- **`reduce` пустого массива без начального значения — `TypeError`.**
- **Копии массивов поверхностные;** `[1] === [1]` ложно.
- **`Set` убирает дубликаты** (сравнение «SameValueZero»: `NaN` равен `NaN`); у `Set` есть операции `union`, `intersection` и другие.
- **`Map` принимает ключи любого типа** (в том числе объекты и `NaN`) и помнит порядок вставки.
- **Слабые коллекции** принимают только объекты в качестве ключей, не итерируются и не мешают сборщику мусора.
- **Типизированные массивы** хранят числа фиксированного типа и «заворачивают» значения (`256` в `Uint8Array` — `0`).

## Минимальный пример

```js
const nums = [3, 1, 2];
console.log(nums.map(n => n * 2), nums.toSorted(), nums);
console.log([...new Set([1, 2, 2, 3])], new Map([['a', 1]]).get('a'));
```

```text
[ 6, 2, 4 ] [ 1, 2, 3 ] [ 3, 1, 2 ]
[ 1, 2, 3 ] 1
```

`toSorted` вернул отсортированную копию, исходный `nums` не изменился.

## Когда применять, а когда нет

| Задача | Выбор |
|---|---|
| Упорядоченный список | `Array` |
| Уникальные значения | `Set` |
| Словарь с произвольными ключами | `Map` |
| Словарь со строковыми ключами и JSON | обычный объект ([модуль 05](../05-objects-and-prototypes/overview.ru.md)) |
| Метаданные, привязанные к объектам, без утечек памяти | `WeakMap` |
| Двоичные данные, байты | типизированные массивы |
| Неизменяемая работа со списком | `toSorted`, `toReversed`, `with`, `toSpliced`, `map`, `filter` |

- ❌ Не используйте `for...in` для массивов: он перебирает ключи-строки и «лишние» свойства.
- ❌ Не добавляйте элементы по огромному индексу: массив станет «дырявым».
