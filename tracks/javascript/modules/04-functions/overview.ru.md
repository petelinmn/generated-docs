# Функции

🌐 **Русский** · [English](overview.en.md)

## Коротко

Функции в JavaScript — полноценные значения: их можно присваивать переменным, передавать в другие функции и возвращать. Есть три основные формы: **объявление** (`function f() {}`), **выражение** (`const f = function () {}`) и **стрелочная функция** (`const f = () => {}`). Главная сложность — ключевое слово **`this`**: у обычных функций оно зависит от того, *как* функцию вызвали, а у стрелочных берётся из окружающего кода. Параметры могут иметь значения по умолчанию и собирать остаток аргументов (`...rest`), лишние аргументы игнорируются, а недостающие равны `undefined`.

## Ключевые идеи

- **Три формы:** объявление (всплывает целиком), выражение и стрелка (всплывают как переменные).
- **Аргументы не проверяются:** лишние отбрасываются, недостающие — `undefined`.
- **Значения по умолчанию вычисляются при каждом вызове** и срабатывают только на `undefined` (но не на `null`).
- **`...rest` собирает остаток аргументов в настоящий массив,** а `arguments` — устаревший псевдомассив (у стрелок своего нет).
- **`this` определяется способом вызова:** `obj.method()` — `obj`; обычный вызов `f()` — `undefined` (в строгом режиме); `call`/`apply`/`bind` задают явно; `new` создаёт объект.
- **У стрелочной функции нет своего `this`, `arguments` и она не может быть конструктором.**
- **Оторванный от объекта метод теряет `this`:** `const g = obj.m; g()`.
- **Функция без `return` возвращает `undefined`;** перенос строки после `return` ломает код.
- **Глубокая рекурсия переполняет стек вызовов** (`RangeError`).

## Минимальный пример

```js
function add(a, b = 10, ...rest) { return [a + b, rest]; }
const double = (n) => n * 2;
console.log(add(1), add(1, 2, 3, 4), [1, 2, 3].map(double));
```

```text
[ 11, [] ] [ 3, [ 3, 4 ] ] [ 2, 4, 6 ]
```

## Когда применять, а когда нет

| Задача | Форма |
|---|---|
| Именованная вспомогательная функция | объявление |
| Короткий обратный вызов (`map`, `filter`) | стрелка |
| Метод объекта или класса, которому нужен `this` | сокращённый метод `m() {}` |
| Конструктор «по-старому» | `function Person()` + `new` (сегодня обычно `class`) |
| Привязать `this` или часть аргументов | `bind` |

- ❌ Не используйте стрелку как метод объекта, если нужен `this` этого объекта.
- ❌ Не передавайте метод как обратный вызов без привязки `this`.
