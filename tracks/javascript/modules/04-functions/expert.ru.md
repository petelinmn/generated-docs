# Функции: экспертная теория

🌐 **Русский** · [English](expert.en.md)

**Уровни:** [обзор](overview.ru.md) · [1. Базовая](basics.ru.md) · [2. Продвинутая](advanced.ru.md) · **3. Экспертная** · [4. Квиз](quiz.ru.md)

Опирается на [базовую](basics.ru.md) и [продвинутую](advanced.ru.md) теорию. Все результаты получены запуском на Node.js 24.15 (ES-модуль, строгий режим), если не указано иное.

## Справочник

### Формы функций

| Форма | Всплытие | Собственный `this` | `arguments` | `new` | `prototype` |
|---|---|---|---|---|---|
| `function f() {}` | целиком | да (по способу вызова) | да | да | есть |
| `const f = function () {}` | как `const`/`var` | да | да | да | есть |
| `const f = () => {}` | как `const`/`var` | нет (лексический) | нет (видит внешний) | нет — `TypeError: arrow is not a constructor` | нет |
| метод `m() {}` в объекте/классе | — | да | да | нет | нет |
| `function*`, `async function`, `async () => {}` | как выше | да (стрелка — нет) | да (стрелка — нет) | нет | у генератора есть |

> ⚠️ Проверить: отсутствие `prototype` и невозможность `new` у методов, генераторов и асинхронных функций, а также `async`-стрелки взяты из спецификации и в опытах не запускались (проверена стрелка).

### Правила `this` (в порядке приоритета)

| Способ вызова | `this` |
|---|---|
| `new F()` | новый объект |
| `bound()` после `f.bind(t)` | `t` (нельзя изменить повторным `call`) |
| `f.call(t)`, `f.apply(t)` | `t` (в строгом режиме без преобразования: `call(5)` → `5`, `call(null)` → `null`) |
| `obj.f()` | `obj` |
| `f()` | `undefined` в строгом режиме; глобальный объект в нестрогом |
| стрелка | `this` внешней области |

В нестрогом коде (`.cjs`): `f()` вернул глобальный объект, `call(5)` — объект-обёртку (`typeof this` — `'object'`), `call(null)` — глобальный объект, а оторванный метод `g()` читает `globalThis.name` и возвращает `undefined` без ошибки.

### Свойства функции

| Свойство | Значение |
|---|---|
| `name` | имя из объявления, переменной или `bound <имя>` у `bind` |
| `length` | число параметров до первого со значением по умолчанию или `...rest` (в опыте `(a, b = 1, ...c) => {}` имеет `length` `1`; у `bind(null, 5)` от трёх параметров — `2`) |
| `prototype` | у обычных функций и классов — объект для `new` |
| `toString()` | исходный текст функции |

## Внутреннее устройство

- **Внутренние методы.** Любая функция — объект с внутренним методом `[[Call]]`; у конструкторов есть ещё `[[Construct]]`. Стрелки и методы его не имеют, поэтому `new arrow()` — `TypeError`.
- **`new F(args)`** по спецификации создаёт объект с прототипом `F.prototype`, вызывает `F` с этим `this` и возвращает результат вызова, если это объект, иначе — созданный объект.
- **Лексический `this`.** Стрелка не создаёт собственную привязку `this`: она ищет `this` по цепочке окружений ([модуль 03](../03-scopes-and-hoisting/expert.ru.md#внутреннее-устройство)) как обычную переменную. Поэтому `call`/`bind` на неё не влияют, а `nested()` в `map` видит `this` метода.
- **Режим определяется кодом, а не вызовом.** Строгая функция получает `this` как есть; нестрогая — подставляет глобальный объект вместо `undefined`/`null` и оборачивает примитивы.
- **Значения по умолчанию.** Параметры с умолчаниями создают отдельную область: выражения вычисляются слева направо при каждом вызове (в опыте `f()` увеличивал счётчик).
- **Стек вызовов.** Каждый вызов добавляет кадр; при переполнении `RangeError: Maximum call stack size exceeded`. Оптимизации хвостовых вызовов в V8 нет (в опыте `depth(n + 1)` упала с ошибкой).

> ⚠️ Проверить: глубина стека в числах, оптимизация хвостовой рекурсии в других движках и подробности `[[Construct]]` для производных классов в опытах не проверялись.

## Подвохи

### 1. Оторванный метод теряет `this`

`const g = obj.m; g()` — `this` равен `undefined` (строгий режим): результат `undefined` при `this?.name`, либо `TypeError: Cannot read properties of undefined` при `this.name` (в опыте на классе). В нестрогом режиме `this` — глобальный объект, и ошибки нет, а значение неверное.

### 2. `map(parseInt)`

`['1','2','3'].map(parseInt)` даёт `[1, NaN, NaN]`: индекс попадает во второй параметр `radix`.

### 3. ASI и `return`

`return` с переводом строки возвращает `undefined` (в опыте `asi()`).

### 4. `null` не активирует значение по умолчанию

`dflt(1, null)` вернул `[1, null, 'lazy']`: умолчание срабатывает только на `undefined`.

### 5. Стрелка в роли метода

`obj.arrow()` вернула `typeof this` равным `'undefined'`: `this` берётся из окружения модуля, а не из `obj`.

### 6. Конструктор без `new`

В строгом режиме `Person('x')` — `TypeError: Cannot set properties of undefined (setting 'name')`. В нестрогом то же присваивание создало бы свойство глобального объекта.

> ⚠️ Проверить: утверждение про нестрогий режим в подвохе 6 следует из правил `this` (в нестрогом режиме `f()` вернул глобальный объект), но само создание глобального свойства конструктором не запускалось.

### 7. `arguments` и стрелки

У стрелки нет своего `arguments`: на верхнем уровне модуля он не определён, а внутри обычной функции стрелка видит `arguments` внешней функции (в опыте).

### 8. `length` не равен числу объявленных параметров

Параметры со значениями по умолчанию и `...rest` не считаются.

### 9. Привязку нельзя изменить

`bound.call({ name: 'x' })` всё равно использует `this`, зафиксированный в `bind`.

## Компромиссы и альтернативы

| Подход | Плюсы | Минусы |
|---|---|---|
| Стрелка | лексический `this`, коротко | нет своих `this`/`arguments`, не конструктор |
| Метод `m() {}` | свой `this`, имя, можно `super` | теряет `this` при передаче |
| `bind` | явная фиксация | создаёт новую функцию, не перепривязывается |
| Поле класса со стрелкой | `this` всегда экземпляр | копия на каждый экземпляр (модуль 06) |
| `class` вместо функции-конструктора | защита от вызова без `new` | синтаксис, наследование через `extends` |
| Функциональный стиль без `this` | проще тестировать | другой стиль кода |

## Вопросы с собеседований

<details><summary>1. Чем различаются объявление функции, функциональное выражение и стрелка?</summary>

Объявление всплывает целиком; выражение и стрелка — значения переменных; у стрелки нет своих `this`, `arguments`, она не конструктор.

→ [Базовая теория](basics.ru.md#три-формы-функций)

</details>

<details><summary>2. Как определяется <code>this</code>?</summary>

По способу вызова: `new`, `bind`, `call`/`apply`, метод объекта, обычный вызов. У стрелки — из внешней области.

→ [Справочник](#правила-this-в-порядке-приоритета)

</details>

<details><summary>3. Ловушка: почему метод, переданный как обратный вызов, «теряет» <code>this</code>?</summary>

Функция вызывается без объекта, поэтому `this` — `undefined` (строгий режим) или глобальный объект. Решение: `bind` или стрелка-обёртка.

→ [Подвох 1](#1-оторванный-метод-теряет-this)

</details>

<details><summary>4. Что делают <code>call</code>, <code>apply</code> и <code>bind</code>?</summary>

`call`/`apply` вызывают функцию с заданным `this` (аргументы списком или массивом), `bind` возвращает новую функцию с зафиксированным `this` и, возможно, началом аргументов.

→ [Продвинутая теория](advanced.ru.md#call-apply-и-bind)

</details>

<details><summary>5. Ловушка: что вернёт <code>['1','2','3'].map(parseInt)</code>?</summary>

`[1, NaN, NaN]`: `map` передаёт индекс как второй аргумент (`radix`).

→ [Подвох 2](#2-mapparseint)

</details>

<details><summary>6. Чем <code>...rest</code> лучше <code>arguments</code>?</summary>

Это настоящий массив, работает в стрелках, явно показан в сигнатуре.

→ [Базовая теория](basics.ru.md#остаточные-параметры-и-arguments)

</details>

<details><summary>7. Когда срабатывает значение параметра по умолчанию?</summary>

Только при `undefined` (в том числе если аргумент не передан); `null` не заменяется. Вычисляется при каждом вызове.

→ [Подвох 4](#4-null-не-активирует-значение-по-умолчанию)

</details>

<details><summary>8. Что делает <code>new</code>?</summary>

Создаёт объект с прототипом `F.prototype`, вызывает `F` с этим `this`, возвращает объект (или явно возвращённый объект).

→ [Внутреннее устройство](#внутреннее-устройство)

</details>

<details><summary>9. Ловушка: что вернёт функция <code>function f() { return\n 42 }</code>?</summary>

`undefined`: ASI вставляет `;` после `return`.

→ [Подвох 3](#3-asi-и-return)

</details>

<details><summary>10. Почему стрелку нельзя использовать с <code>new</code>?</summary>

У неё нет внутреннего метода `[[Construct]]` и `prototype`: `TypeError: arrow is not a constructor`.

→ [Продвинутая теория](advanced.ru.md#ограничения-стрелочных-функций)

</details>

<details><summary>11. Что такое <code>new.target</code>?</summary>

Значение внутри функции, показывающее, вызвана ли она через `new` (иначе `undefined`); используется для защиты от вызова без `new` и для абстрактных классов.

→ [Продвинутая теория](advanced.ru.md#newtarget)

</details>

<details><summary>12. Чем отличается поведение <code>this</code> в строгом и нестрогом режиме?</summary>

В строгом `f()` даёт `undefined`, `call(5)` — `5`, `call(null)` — `null`; в нестрогом — глобальный объект и обёртка.

→ [Справочник](#правила-this-в-порядке-приоритета)

</details>

## Шпаргалка

```text
function f() {}  const f = function () {}  const f = () => {}
f.call(t, a, b)  f.apply(t, [a, b])  const g = f.bind(t, a)
f(...args)  function (a, b = 1, ...rest)
this: new > bind > call/apply > obj.f() > f() (undefined в strict) ; стрелка — внешний this
new.target ; f.name ; f.length (без default и rest)
```

- Метод как callback → `bind` или стрелка.
- `return` и значение — на одной строке.
- Стрелка не конструктор и без своего `this`.
