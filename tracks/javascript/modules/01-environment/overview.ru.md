# Окружение и инструменты

🌐 **Русский** · [English](overview.en.md)

## Коротко

JavaScript можно запускать в браузере и в **Node.js** — рантайме, построенном на движке V8. Для первых шагов нужен только Node.js: он запускает файлы (`node файл.js`), выполняет выражения из командной строки (`node -p`, `node -e`) и содержит интерактивную консоль (REPL). Вместе с Node.js ставится менеджер пакетов **npm**, а проект описывает файл `package.json`. Его поле `"type"` решает, как Node.js читает `.js`-файлы: как модули ES (`"module"`) или как CommonJS (`"commonjs"`).

## Ключевые идеи

- **`node файл.js` запускает программу;** `node -p "выражение"` печатает результат, `node -e "код"` выполняет код, `node` без аргументов открывает REPL.
- **Аргументы командной строки лежат в `process.argv`:** первые два элемента — путь к Node.js и к скрипту, дальше ваши.
- **`package.json` — паспорт проекта:** имя, версия, скрипты, зависимости и `"type"`.
- **Два модульных формата: ESM и CommonJS.** В ESM нет `require`, но есть `import`, `import.meta` и `await` на верхнем уровне. Расширения `.mjs` и `.cjs` фиксируют формат независимо от `"type"`.
- **ESM работает в строгом режиме,** CommonJS по умолчанию — в нестрогом (например, присваивание необъявленной переменной).
- **В Node.js 24 есть встроенный тестовый раннер** (`node --test`, модуль `node:test`), поддержка `.env` (`--env-file`) и запуск скриптов (`node --run`).
- **Браузерных глобальных объектов нет:** `window` и `document` отсутствуют, а `globalThis` и `process` есть.

## Минимальный пример

```js
// hello.js
console.log('Hello,', process.argv[2] ?? 'world');
```

```text
$ node hello.js Ada
Hello, Ada
$ node -p "1 + 1"
2
```

## Когда применять, а когда нет

| Задача | Инструмент |
|---|---|
| Проверить выражение | `node -p "..."` или REPL |
| Запустить скрипт | `node файл.js` |
| Запустить тесты | `node --test` / `npm test` |
| Подключить стороннюю библиотеку | `npm install <пакет>` |
| Работа с DOM, `window` | браузер (модуль 17 дорожной карты) |

- ❌ Не ставьте глобально пакеты, нужные проекту: фиксируйте их в `package.json`.
- ❌ Не пишите новый код на CommonJS без причины: стандарт — модули ES.
