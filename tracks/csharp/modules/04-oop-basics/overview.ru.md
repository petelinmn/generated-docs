# ООП: классы и объекты

🌐 **Русский** · [English](overview.en.md)

## Коротко

Класс описывает тип: данные (поля, свойства) и поведение (методы). Объект — экземпляр класса в управляемой куче, созданный через `new`. Объектно-ориентированный подход строится на инкапсуляции (состояние скрыто за свойствами и методами), наследовании (класс расширяет другой) и полиморфизме (поведение определяется фактическим типом объекта). В C# 15 классы получили первичные конструкторы, `required`, `init` и ключевое слово `field`.

## Ключевые идеи

- **Класс — ссылочный тип:** переменная хранит ссылку, `==` и `Equals` по умолчанию сравнивают ссылки.
- **Инкапсуляция:** поля `private`, наружу — свойства; шесть уровней доступа, по умолчанию члены `private`, типы `internal`.
- **Свойства:** автосвойства, `init`, `private set`, `required`, `field` для логики без своего поля.
- **Конструкторы:** цепочки `this(...)`/`base(...)`, первичные конструкторы, статический конструктор.
- **Полиморфизм:** `virtual` + `override`; `new` только скрывает член — результат зависит от типа переменной.
- **Порядок инициализации:** поля наследника → поля базы → конструктор базы → конструктор наследника; виртуальный вызов в конструкторе видит недостроенный объект.
- **Композиция часто лучше наследования:** наследуй для «является», иначе храни объект в поле.

## Минимальный пример

```csharp
Animal animal = new Dog();
Console.WriteLine(animal.Speak());     // Woof — decided by the actual type

public class Animal
{
    public virtual string Speak() => "...";
}

public class Dog : Animal
{
    public override string Speak() => "Woof";
}
```

## Когда применять, а когда нет

- ✅ Классы — для сущностей с идентичностью и изменяемым состоянием, для типов с поведением.
- ✅ Наследование — для настоящего отношения «является» и общей реализации.
- ✅ `sealed` — по умолчанию для классов, не рассчитанных на наследование.
- ❌ Наследование ради повторного использования кода — берите композицию.
- ❌ Виртуальные вызовы в конструкторах.
- ❌ Скрытие `new` — используйте `override` или другое имя.
