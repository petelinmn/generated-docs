# Современный C#

🌐 **Русский** · [English](overview.en.md)

## Коротко

Современный C# (версии 9–15) убирает шаблонный код: образцы заменяют цепочки `if` и приведений, `switch`-выражения возвращают значения, первичные конструкторы и `required`/`init` сокращают описание типов, выражения коллекций унифицируют создание массивов и списков. Новейшие возможности — extension members (C# 14) и union-типы (C# 15) — расширяют систему типов. Старый код продолжает работать, но в новом коде и документации вы встретите именно эти конструкции.

## Ключевые идеи

- **Образцы (patterns):** тип, константа, реляционные, логические (`and`/`or`/`not`), свойств, позиционные, списочные; применяются в `is` и `switch`.
- **`switch`-выражение** возвращает значение; ветви идут сверху вниз; неполное покрытие — предупреждение `CS8509` и `SwitchExpressionException` на runtime.
- **Первичные конструкторы:** параметры типа доступны во всём теле; в `class`/`struct` это скрытые поля, а не свойства (в `record` — свойства).
- **Выражения коллекций:** `[1, 2, ..other]` создаёт массив, список, `Span<T>` или свой тип по целевому типу.
- **`required` + `init`** задают неизменяемые объекты без громоздких конструкторов; `field` убирает ручные поля в свойствах.
- **Extension members** добавляют типам свойства и статические члены; `?.=` присваивает только при ненулевом объекте.
- **Union-типы (C# 15):** значение одного из перечисленных типов, с проверкой полноты `switch`.

## Минимальный пример

```csharp
static string Describe(int[] xs) => xs switch
{
    [] => "empty",
    [var only] => $"one: {only}",
    [var first, .., var last] => $"{first}..{last}",
};

int[] data = [1, 2, 3];
Console.WriteLine(Describe(data));   // 1..3
```

## Когда применять, а когда нет

- ✅ Разбор данных по форме: команды, сообщения, протоколы — образцы.
- ✅ DTO и конфигурации — `required` + `init` или записи.
- ✅ Создание коллекций — выражения коллекций.
- ❌ Сложная логика внутри `when` и вложенных образцов: вынесите её в метод.
- ❌ Первичные конструкторы, когда нужны публичные свойства с логикой, — объявите их явно.
- ❌ Union-типы в публичных API, пока возможность новая и меняется.
