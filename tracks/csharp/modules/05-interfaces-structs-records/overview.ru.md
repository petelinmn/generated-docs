# Интерфейсы, структуры, записи

🌐 **Русский** · [English](overview.en.md)

## Коротко

Кроме классов, в C# есть три инструмента для описания типов. Интерфейс задаёт контракт без реализации; структура — значимый тип, который копируется при присваивании; запись (`record`) — тип для данных с автоматическим равенством по значению, `ToString`, `with` и деконструкцией. Выбор между ними определяет, как объекты хранятся, копируются и сравниваются.

## Ключевые идеи

- **Интерфейс — контракт:** класс реализует сколько угодно интерфейсов; с C# 8 есть реализации по умолчанию, с C# 11 — `static abstract` члены.
- **Явная реализация** разрешает конфликты имён: `IA.Run` и `IB.Run` в одном классе.
- **Структура — значимый тип:** присваивание копирует; нет наследования; изменяемые структуры порождают скрытые копии, поэтому структуры делают `readonly`.
- **Запись — данные с равенством по значению:** `==`, `Equals`, `GetHashCode`, `ToString`, `with`, деконструкция; `with` копирует поверхностно.
- **Равенство:** класс по умолчанию сравнивается по ссылке, структура и запись — по значению; `Equals` и `GetHashCode` переопределяют вместе.
- **Ключи коллекций неизменяемы:** изменение хеша «теряет» элемент в `HashSet`.
- **Упаковка:** структура через интерфейсный параметр — выделение 24 байт; через обобщённый метод с ограничением — нет.

## Минимальный пример

```csharp
public record Person(string Name, int Age);

var a = new Person("Ann", 30);
var b = new Person("Ann", 30);

Console.WriteLine(a == b);                // True — equality by value
Console.WriteLine(a with { Age = 31 });   // Person { Name = Ann, Age = 31 }
```

## Когда применять, а когда нет

- ✅ Интерфейс — контракт, сменные реализации, подмена в тестах.
- ✅ `record` — DTO, сообщения, ключи словарей, значения предметной области.
- ✅ `readonly record struct` — маленькие неизменяемые значения.
- ❌ `record` для сущностей с идентичностью и изменяемым состоянием — равенство по значению им вредит.
- ❌ Изменяемые или большие структуры.
- ❌ Интерфейс «на всякий случай» с единственной реализацией.
