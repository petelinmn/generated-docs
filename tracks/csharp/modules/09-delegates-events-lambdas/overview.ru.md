# Делегаты, события, лямбды

🌐 **Русский** · [English](overview.en.md)

## Коротко

Делегат — типобезопасная ссылка на метод: его можно хранить в переменной, передавать в другие методы и вызывать позже. Лямбда-выражение — короткая запись анонимного метода, которую присваивают делегату (`Func`, `Action`, `Predicate`). Событие — делегат, защищённый так, что снаружи на него можно только подписаться и отписаться, а вызывает его сам издатель. На этих трёх возможностях построены LINQ, обработчики в UI и веб-фреймворках, обратные вызовы и асинхронный код.

## Ключевые идеи

- **Делегат — запечатанный класс** (наследник `MulticastDelegate`) с целью и методом; готовые типы — `Func`, `Action`, `Predicate`, `EventHandler<T>`.
- **Многоадресность:** `+=`/`-=` создают новый делегат; результат — последнего метода; исключение прерывает цепочку.
- **Лямбды:** выражение или блок, естественный тип (`var`), `static`-лямбда не захватывает переменные.
- **Замыкание захватывает переменную, а не значение:** компилятор переносит её в поле скрытого класса, одного на всю область — он может удерживать лишние объекты.
- **Стоимость:** лямбда без захвата и статическая группа методов — 0 байт (кеш), с захватом — 80 байт, метод экземпляра — 56 байт на преобразование.
- **События:** поле-делегат плюс `add`/`remove`; вызывать только через `?.Invoke`; подписчик удерживается издателем — отписывайтесь.
- **Нельзя отписаться «такой же» лямбдой:** делегаты равны по методу и цели.

## Минимальный пример

```csharp
public class Counter
{
    public event Action? Clicked;                  // the event

    public void Click() => Clicked?.Invoke();      // only the owner raises it
}

var c = new Counter();
c.Clicked += () => Console.WriteLine("clicked");   // subscribe
c.Click();                                         // clicked
```

## Когда применять, а когда нет

- ✅ Передать поведение методу: сортировка, фильтрация, обратные вызовы, LINQ.
- ✅ Уведомления между объектами — `event` и `EventHandler<T>`.
- ✅ `static`-лямбды и делегаты, созданные один раз, в горячем коде.
- ❌ Публичное поле-делегат вместо `event`.
- ❌ Подписка на долгоживущий объект без отписки.
- ❌ Исключения из обработчиков многоадресных делегатов: они прерывают цепочку.
