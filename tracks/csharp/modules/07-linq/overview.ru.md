# LINQ

🌐 **Русский** · [English](overview.en.md)

## Коротко

LINQ (Language Integrated Query) — единый способ запрашивать данные из любых последовательностей: фильтровать, преобразовывать, сортировать, группировать, соединять и агрегировать. Запросы пишутся цепочкой методов (`Where`, `Select`, `OrderBy`, …) или в SQL-подобном синтаксисе, а в `IQueryable` те же выражения переводятся в SQL. Ключевая идея — отложенное выполнение: запрос выполняется при перечислении, а не при объявлении.

## Ключевые идеи

- **Операторы — методы расширения** `IEnumerable<T>`; запросный синтаксис компилятор переписывает в вызовы методов.
- **Отложенное выполнение:** запрос видит изменения источника и захваченных переменных; `ToList()` фиксирует снимок.
- **Стриминг и буферизация:** `Where`/`Select` отдают элементы по одному, `OrderBy`/`GroupBy` читают всё, `Join` — всю вторую последовательность.
- **Многократный перебор** выполняет запрос и его источник заново: материализуйте результат.
- **Пустые данные:** `First`/`Single`/`Max` бросают исключения, `FirstOrDefault` и `Max` для `int?` — нет; `Sum` для `int` проверяет переполнение.
- **Итераторы `yield`** — конечные автоматы: ленивы, проверка аргументов откладывается.
- **`IEnumerable` или `IQueryable`:** делегат в памяти или дерево выражений для провайдера (EF Core).

## Минимальный пример

```csharp
var people = new[] { new P("Ann", "IT", 30), new P("Bob", "HR", 25), new P("Cid", "IT", 35) };

var names = people
    .Where(p => p.Age > 26)
    .OrderByDescending(p => p.Age)
    .Select(p => p.Name)
    .ToList();                                  // Cid, Ann

record P(string Name, string Dept, int Age);
```

## Когда применять, а когда нет

- ✅ Фильтрация, проекция, группировка и соединение коллекций в читаемом виде.
- ✅ Запросы к базе данных через EF Core.
- ✅ Ленивые последовательности (`yield`).
- ❌ Побочные эффекты в `Where`/`Select`.
- ❌ Многократный перебор «ленивого» источника без материализации.
- ❌ LINQ в самом горячем коде без замеров — цикл может быть быстрее.
