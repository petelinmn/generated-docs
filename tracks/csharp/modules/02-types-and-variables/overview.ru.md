# Типы и переменные

🌐 **Русский** · [English](overview.en.md)

## Коротко

C# — статически типизированный язык: тип каждой переменной известен при компиляции. Все типы делятся на значимые (числа, `bool`, `char`, структуры), которые копируются по значению, и ссылочные (классы, `string`, массивы), которые разделяются по ссылке. От этого различия зависят поведение присваивания, передачи в методы, сравнения и работа с `null`.

## Ключевые идеи

- **`var` — не динамическая типизация:** тип выводится один раз при компиляции.
- **Значимый тип копируется** при присваивании и передаче в метод, **ссылочный — нет**: обе переменные указывают на один объект.
- **Преобразования:** неявные — без потери данных, явные `(int)x` — с возможной потерей. Переполнение `int` по умолчанию молча «заворачивается», `checked` превращает его в исключение.
- **Строки неизменяемы**, сравниваются по содержимому. Есть интерполяция `$"…"`, verbatim `@"…"` и raw-литералы `"""…"""`.
- **Null:** `int?` — отдельный тип `Nullable<int>`. `string?` — аннотация для компилятора, которая включает предупреждения о возможном `null`. Операторы `?.`, `??`, `??=`.
- **`double` неточен** (`0.1 + 0.2 != 0.3`), для денег — `decimal`.
- **Культура** влияет на регистр, сравнение и формат чисел. Для идентификаторов и ключей используют `Ordinal` и `InvariantCulture`.

## Минимальный пример

```csharp
public static (int Original, int Copy) MutateStructCopy()
{
    var original = new PointStruct { X = 1 };
    var copy = original;
    copy.X = 99;
    return (original.X, copy.X);
}

public static (int Original, int Copy) MutateClassCopy()
{
    var original = new PointClass { X = 1 };
    var copy = original;
    copy.X = 99;
    return (original.X, copy.X);
}
```

`MutateStructCopy()` → `(1, 99)`: структура скопировалась. `MutateClassCopy()` → `(99, 99)`: обе переменные ссылаются на один объект.

## Когда применять, а когда нет

- ✅ `decimal` — для денег и точной десятичной арифметики; `double` — для измерений и вычислений.
- ✅ `int?` — когда «значения нет» является нормальным результатом.
- ✅ `<Nullable>enable</Nullable>` — во всех новых проектах.
- ✅ `TryParse` с явной культурой — для разбора ввода.
- ❌ Изменяемые структуры: копирование делает изменения «невидимыми».
- ❌ Оператор `!` для подавления nullable-предупреждений без реальной гарантии.
- ❌ `==` для `double` и для упакованных значений.
