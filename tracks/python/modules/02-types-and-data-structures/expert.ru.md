# Типы и структуры данных: экспертная теория

Опирается на [продвинутую теорию](advanced.ru.md).

## Справочник встроенных контейнеров

| Тип | Изменяемость | Уникальность | Порядок | Применение |
|---|---|---|---|---|
| `list` | изменяемый | нет | сохраняется | последовательность с частыми изменениями |
| `tuple` | неизменяемый контейнер | нет | сохраняется | запись или ключ |
| `dict` | изменяемый | ключи уникальны | сохраняется в версии вставки | поиск по ключу |
| `set` | изменяемый | уникальные элементы | не гарантируется | операции множеств |
| `frozenset` | неизменяемый | уникальные элементы | не гарантируется | неизменяемое множество |
| `range` | неизменяемый | нет | сохраняется | числовая последовательность |

## Модель объектов

Каждый объект имеет идентичность, тип и значение. Идентичность неизменна для существующего объекта, тип определяет поддерживаемые операции, а значение может меняться у mutable-типов.

Переменные не содержат сами объекты: они являются ссылками на объекты. Поэтому присваивание не копирует контейнер.

## Внутреннее устройство ссылок

CPython использует подсчёт ссылок и дополнительный обнаружитель циклов. Когда объект достигает нуля ссылок, он может освободиться сразу. Циклические группы обнаруживаются отдельно.

Не следует полагаться на немедленное срабатывание сборки мусора в переносимом коде или финализацию по выходу из функции. Реализации Python могут отличаться.

## Хешируемость

Словари и множества требуют хешируемых ключей. Пользовательский неизменяемый объект хешируется, только если реализует совместимые `__hash__` и `__eq__`.

## Подвохи

### 1. Кортеж с изменяемым содержимым

```python
value = ([1],)
try:
    hash(value)
except TypeError as error:
    print(type(error).__name__)
```

Кортеж неизменяем как контейнер ссылок, но вложенный список остаётся изменяемым.

### 2. Срез создает копию

```python
a = [[1]]
b = a[:]
b[0].append(2)
print(a)
```

Для вложенного списка нужна глубокая копия.

### 3. Сравнение чисел

```python
print(0.1 + 0.2 == 0.3)
```

```text
False
```

Для приближённого сравнения задавайте допуск; для денег используйте точное представление.

### 4. Хеш по времени процесса

Для строк и байтов хеш может быть salted и отличаться между запусками интерпретатора. Не сохраняйте хеш в базе как стабильный ключ.

## Вопросы с собеседований

<details><summary>1. Чем отличается `==` от `is`?</summary>

`==` вызывает семантику равенства объектов, а `is` проверяет тот же объект. Для `None` используйте `is`.

</details>

<details><summary>2. Почему список нельзя сделать ключом словаря?</summary>

Он изменяемый и не хешируемый. Изменение после добавления нарушило бы структуру словаря.

</details>

<details><summary>3. Является ли кортеж полностью неизменяемым?</summary>

Сам кортеж не меняет набор своих ссылок, но ссылки могут вести к изменяемым объектам.

</details>

<details><summary>4. Чем copy отличается от deepcopy?</summary>

`copy` копирует верхний уровень; `deepcopy` рекурсивно копирует вложенные mutable-объекты.

</details>

<details><summary>5. Почему `0.1 + 0.2 != 0.3`?</summary>

Оба числа двоичного формата представляют дроби приближённо. Результат отличается от литерального `0.3`.

</details>

<details><summary>6. Что значит передача аргумента в Python?</summary>

Передаётся ссылка на объект, а не копия объекта. Переприсваивание параметра не меняет исходную переменную.

</details>

<details><summary>7. Почему set не гарантирует порядок?</summary>

Он оптимизирован под уникальность и хешированные поиски. Порядок зависит от таблицы и хешей.

</details>

<details><summary>8. Как устроен словарь на высоком уровне?</summary>

Это хеш-таблица ключей и значений. Ключ используется для вычисления ячейки, а сравнение разрешает коллизии.

</details>

<details><summary>9. Нужно ли вручную освобождать память после удаления переменной?</summary>

Нет, переменная сама не является аллокатором. Освобождение происходит реализацией сборщика мусора.

</details>

<details><summary>10. Чем `range` отличается от `list`?</summary>

`range` хранит параметры последовательности и создаёт элементы лениво-представимым образом; `list` хранит ссылки на элементы.

</details>

<details><summary>11. Какой тип подходит для неизменяемого множества?</summary>

`frozenset`.

</details>

<details><summary>12. Может ли словарь иметь ключ с пользовательским равенством?</summary>

Да, если объект хешируем и совместимым образом определены `__hash__` и `__eq__`.

</details>

## Компромиссы и альтернативы

Используйте `Decimal` для финансовых и точных десятичных вычислений. Для числовых массивов используйте специализированные библиотеки, а для структур с именованными полями — dataclass или TypedDict.
