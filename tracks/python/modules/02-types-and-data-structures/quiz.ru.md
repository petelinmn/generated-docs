# Квиз: типы и структуры данных

🌐 **Русский** · [English](quiz.en.md)

> Сначала ответьте сами, потом откройте ответ. Метка показывает уровень: 🟢 [базовая](basics.ru.md) · 🟡 [продвинутая](advanced.ru.md) · 🔴 [экспертная](expert.ru.md).

## 1. 🟢 Какой оператор проверяет идентичность двух переменных?

- A) `==`
- B) `is`
- C) `===`
- D) `typeof`

<details><summary>Ответ</summary>

**B.** `is` проверяет, что обе ссылки ведут к одному объекту.
→ [Базовая теория](basics.ru.md#значения-и-ссылки)

</details>

## 2. 🟢 Какой тип изменяемый?

- A) `tuple`
- B) `str`
- C) `list`
- D) `frozenset`

<details><summary>Ответ</summary>

**C.** `list` можно менять методами `append`, `pop`, срезами и присваиванием.

</details>

## 3. 🟢 Что выведет `{"a": 1}.get("b", "unknown")`?

- A) `None`
- B) `KeyError`
- C) `"unknown"`
- D) `False`

<details><summary>Ответ</summary>

**C.** `dict.get` возвращает значение по умолчанию, если ключ отсутствует.

</details>

## 4. 🟢 Можно ли использовать список как ключ словаря?

- A) Да, всегда
- B) Нет, список не хешируемый
- C) Да, если его длина меньше 10
- D) Только внутри кортежа

<details><summary>Ответ</summary>

**B.** Ключ словаря должен быть хешируемым.

</details>

## 5. 🟡 Что выведет этот код?

```python
a = [1, 2]
b = a
b.append(3)
print(a)
```

- A) `[1, 2]`
- B) `[1, 2, 3]`
- C) `[3]`
- D) Ошибка

<details><summary>Ответ</summary>

**B.** `a` и `b` ссылаются на один изменяемый список.

</details>

## 6. 🟡 Что отличает неглубокую копию от глубокой?

- A) Ничего
- B) Глубокая копирует и вложенные изменяемые объекты
- C) Неглубокая копия копирует весь граф
- D) Глубокая копия создаёт тот же объект

<details><summary>Ответ</summary>

**B.** `copy()` копирует верхний уровень, `deepcopy()` обрабатывает вложенность.

</details>

## 7. 🟡 Чему равно `0.1 + 0.2 == 0.3`?

- A) `True`
- B) `False`
- C) `None`
- D) Зависит от ОС

<details><summary>Ответ</summary>

**B.** Двоичные float приближённо представляют эти значения.

</details>

## 8. 🟡 Выберите все неизменяемые контейнеры

- [ ] A) `tuple`
- [ ] B) `frozenset`
- [ ] C) `list`
- [ ] D) `dict`

<details><summary>Ответ</summary>

**A, B.** Кортеж и frozenset нельзя изменить через собственные методы.

</details>

## 9. 🔴 Найдите ошибку

```python
scores = {[1, 2]: "Ada"}
```

<details><summary>Ответ</summary>

Список не хешируемый. Для ключа словаря замените список кортежем:

```python
scores = {(1, 2): "Ada"}
```

</details>

## 10. 🔴 Открытый вопрос

Объясните, почему кортеж с элементом `[1]` не является полностью hashable и как это связано с вложенной изменяемостью.

<details><summary>Ключевые пункты ответа</summary>

- Сам кортеж неизменяем как контейнер ссылок.
- Но его элемент — изменяемый список.
- Список не хешируемый, поэтому операция хеширования всего кортежа завершается `TypeError`.

</details>
