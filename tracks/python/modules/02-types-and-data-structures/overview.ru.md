# Типы и структуры данных

🌐 **Русский** · [English](overview.en.md)

## Коротко

Python представляет данные объектами: у каждого объекта есть идентичность, тип и значение. Встроенные типы покрывают числа, строки, логические значения, последовательности, отображения и множества. Большинство контейнеров передаются по ссылке, а не копируются. Понимание изменяемости и идентичности помогает предсказывать поведение кода.

## Ключевые идеи

- **У переменной нет собственного фиксированного типа:** тип принадлежит объекту.
- **`is` сравнивает идентичность, `==` — значение.**
- **`int`, `float`, `str`, `tuple` и другие неизменяемые типы нельзя изменить после создания.**
- **`list`, `dict` и `set` изменяемы:** одна ссылка на них может увидеть изменения через другую.
- **Кортеж неизменяем, но может содержать изменяемые элементы.**
- **Срезы и копии создают новые контейнеры, но не всегда глубокие копии.**
- **Потеря ссылок приводит к сборке мусора, а не к немедленной гарантированной очистке памяти.**

## Минимальный пример

```python
numbers = [1, 2, 3]
alias = numbers
alias.append(4)

print(numbers)
print(numbers is alias)
print(numbers == alias)
print(type(numbers).__name__)
```

```text
[1, 2, 3, 4]
True
True
list
```

## Когда применять

- ✅ Используйте `list` для упорядоченной изменяемой коллекции.
- ✅ Используйте `tuple` для неизменяемой записи или ключа.
- ✅ Используйте `dict` для именованных пар ключ–значение.
- ✅ Используйте `set` для уникальных неупорядоченных элементов.
- ❌ Не используйте изменяемый объект как ключ словаря или элемента множества.
- ❌ Не полагайтесь на уникальный одиночный объект типа `None`; используйте `is None`.
