# Квиз: представления и функции

🌐 **Русский** · [English](quiz.en.md)

> Сначала ответь сам, потом раскрывай ответ. Отметка показывает уровень: 🟢 [базовая теория](basics.ru.md) · 🟡 [продвинутая](advanced.ru.md) · 🔴 [экспертная](expert.ru.md).

## 1. 🟢 Что хранит обычное представление?

- A) Копию строк
- B) Запрос
- C) Индекс
- D) Результат в кэше на минуту

<details><summary>Ответ</summary>

**B.** Строки читаются из таблиц при каждом обращении.

→ [Базовая теория](basics.ru.md)

</details>

- A) В `FROM`
- B) Только через `CALL`
- C) Только в триггерах
- D) В `CREATE INDEX`

<details><summary>Ответ</summary>

**A.**

→ [Базовая теория](basics.ru.md)

</details>

## 3. 🟢 Что выведет запрос?

```sql
SELECT price_with_tax(10, rate => 0.1);
```

<details><summary>Ответ</summary>

```text
11.00
```

Именованный аргумент заменяет значение по умолчанию.

→ [Базовая теория](basics.ru.md)

## 5. 🟡 Представление фильтрует `WHERE active` без check option. Что будет при вставке неактивной строки через него?

- C) Ничего не вставляется
- D) Строка станет активной

## 8. 🟡 Выбери все верные утверждения

- [ ] A) Триггер на оператор срабатывает, даже если строки не менялись
- [ ] B) Возвращаемое значение строкового `AFTER`-триггера игнорируется
- [ ] C) Функция может делать `COMMIT` в теле
- [ ] D) Триггеры `INSTEAD OF` — для представлений

<details><summary>Ответ</summary>

**A, B, D.** Управление транзакциями — у процедур, не у функций.

→ [Продвинутая теория](advanced.ru.md)

</details>

## 9. 🟡 Найди уязвимость

```sql
EXECUTE 'SELECT count(*) FROM ' || tbl;
```

<details><summary>Ответ</summary>

SQL-инъекция через `tbl`. Нужен `format('... %I', tbl)`.

→ [Продвинутая теория](advanced.ru.md)

</details>

## 12. 🔴 Открытый вопрос: когда вы откажетесь выносить правило в триггер?

<details><summary>Ключевые пункты ответа</summary>

- Оно вызывает внешние сервисы или должно выполниться после фиксации.
- Его можно выразить ограничением.
- Массовые изменения станут слишком медленными или поведение неожиданным.
- Команда не может его тестировать и версионировать.

→ [Экспертная теория](expert.ru.md)

</details>
