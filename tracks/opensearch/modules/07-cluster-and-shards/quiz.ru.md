# Квиз: кластер и шарды

🌐 **Русский** · [English](quiz.en.md)

> Сначала ответьте сами, затем раскройте ответ. 🟢 [базовый](basics.ru.md) · 🟡 [продвинутый](advanced.ru.md) · 🔴 [экспертный](expert.ru.md).

## 1. 🟢 Что значит статус yellow?

- A) кластер только для чтения
- B) мало места на диске
- C) первичные есть, часть реплик не назначена
- D) часть данных недоступна

<details><summary>Ответ</summary>

**C.** Yellow означает, что все данные доступны, но избыточность неполная. Недоступные данные — это red, а режим только для чтения статусом не обозначается.
→ [Базовая теория](basics.ru.md)

</details>

## 2. 🟢 Что можно изменить у существующего индекса настройкой?

- A) число реплик
- B) число первичных шардов
- C) оба
- D) ни то, ни другое

<details><summary>Ответ</summary>

**A.** Реплики можно добавить и убрать в любой момент. Число первичных шардов задаётся при создании: для изменения нужны split, shrink или reindex.
→ [Базовая теория](basics.ru.md)

</details>

## 3. 🟢 3 первичных и 2 реплики. Сколько всего копий?

- A) 5
- B) 6
- C) 3
- D) 9

<details><summary>Ответ</summary>

**D.** Реплики считаются на каждый первичный шард: 3 × (1 + 2) = 9.
→ [Базовая теория](basics.ru.md)

</details>

## 4. 🟢 Узел ушёл. Когда по умолчанию начнут строить его реплики заново?

- A) никогда без команды
- B) через 1 минуту
- C) сразу
- D) через 30 минут

<details><summary>Ответ</summary>

**B.** По умолчанию распределение откладывается на минуту (`delayed_timeout`), чтобы перезапустившийся узел успел вернуться без копирования. Ручной команды не требуется.
→ [Базовая теория](basics.ru.md)

</details>

## 5. 🟡 4 копии шарда на 3 узлах. Результат?

- A) red
- B) yellow, одна копия не назначена
- C) две копии на одном узле
- D) ошибка при изменении настройки

<details><summary>Ответ</summary>

**B.** Две копии одного шарда не размещаются на одном узле, поэтому четвёртой нет места. Данные доступны, значит, статус yellow, а настройка принимается без ошибки.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 6. 🟡 Принудительные зоны a,b,c, 2 реплики, зона c потеряна. Что с индексом?

- A) становится green на двух узлах
- B) становится red
- C) удаляется
- D) остаётся yellow

<details><summary>Ответ</summary>

**D.** Принудительная осведомлённость о зонах не даёт собрать все копии в оставшихся зонах: копия для зоны c ждёт её возвращения. Данные при этом доступны, поэтому не red.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 7. 🟡 Поиск с `routing=acme` в индексе из 3 шардов опросит:

- A) 1 шард
- B) 3 шарда
- C) все узлы
- D) только реплики

<details><summary>Ответ</summary>

**A.** Routing вычисляет единственный шард, где лежат документы с этим значением, и поиск идёт только туда — на любую его копию.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 8. 🟡 Что освобождает узел от шардов перед выводом из работы?

- A) `_refresh`
- B) `_close`
- C) `cluster.routing.allocation.exclude._name`
- D) `number_of_replicas: 0`

<details><summary>Ответ</summary>

**C.** Исключение по имени узла заставляет кластер переместить с него шарды. Refresh и close этого не делают, а нулевое число реплик только снижает надёжность.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 9. 🔴 Остались 1 из 3 управляющих узлов-кандидатов. Что верно?

- [ ] A) поиск по локальным шардам ещё может отвечать
- [ ] B) оставшийся узел выбирает себя
- [ ] C) всё работает как обычно
- [ ] D) состояние кластера изменить нельзя

<details><summary>Ответ</summary>

**A, D.** Без большинства голосов не выбрать управляющий узел, и состояние кластера не меняется; чтение из локальных шардов ещё возможно. Одиночный узел сам себя не назначает.
→ [Экспертная теория](expert.ru.md)

</details>

## 10. 🔴 `_count` по red-индексу:

- A) вернёт 0
- B) может вернуть неполное число без ошибки
- C) всегда ошибка
- D) всегда точен

<details><summary>Ответ</summary>

**B.** Поиск по умолчанию допускает частичные результаты: недоступные шарды пропускаются, и число может быть заниженным. Поэтому проверяйте `_shards.failed` и статус.
→ [Экспертная теория](expert.ru.md)

</details>

## 11. 🔴 Shrink индекса из 4 шардов возможен до:

- A) 8
- B) любого меньшего числа
- C) 2 или 1
- D) 3

<details><summary>Ответ</summary>

**C.** Shrink требует, чтобы новое число делило исходное: для 4 это 2 или 1. Тройка не подходит, а увеличение до 8 — это split.
→ [Экспертная теория](expert.ru.md)

</details>

## 12. 🔴 Открытый вопрос: кластер стал red после отказа узла. Порядок действий?

<details><summary>Ответ</summary>

Выяснить, какие индексы и шарды без первичных (`_cat/shards`, `allocation/explain`); вернуть узел и его диск; если копий нет, восстановить из снимка. Принудительное назначение пустого первичного теряет данные — только осознанно и в крайнем случае.
→ [Экспертная теория](expert.ru.md)

</details>
