# Работа с документами и цитаты

🌐 **Русский** · [English](overview.en.md)

## Коротко

Claude принимает не только текст: в сообщение пользователя можно положить PDF и обычные текстовые документы (блок `document`) и изображения (блок `image`). Источник задают тремя способами: base64, URL или `file_id` из Files API. Если включить цитаты (`citations: {enabled: true}`), ответ будет разбит на текстовые блоки, к которым привязаны ссылки на точные места в документе: символы, страницы или блоки. Это основа ответов с проверяемыми источниками.

## Ключевые идеи

- **Документ или изображение — блок в `content`** сообщения пользователя; документы и изображения лучше ставить **до** текста вопроса.
- **Три источника:** `base64`, `url`, `file` (`file_id`). На некоторых платформах доступен только base64.
- **Лимиты запроса:** PDF — до 600 страниц (100 для моделей с контекстом меньше 1M); запрос — до 128 МБ; изображений — до 100 или 600 за запрос.
- **Цена в токенах:** страница PDF — обычно 1500–3000 токенов текста плюс токены изображения; изображение считается по патчам 28×28.
- **Files API** загружает файл один раз, чтобы потом ссылаться на него по `file_id` и не пересылать base64 в каждом ходе.
- **Цитаты:** `citations: {enabled: true}` на документе; ответ — список блоков `text`, у которых есть массив `citations` с `cited_text` и расположением.
- **Три вида расположения:** `char_location` (текст), `page_location` (PDF), `content_block_location` (свои блоки).
- **`cited_text` не считается выходными токенами.**
- **Цитаты несовместимы с `output_config.format`** (структурированный вывод): запрос вернёт 400.
- **Кэшируйте документ** целиком: `cache_control` на блоке верхнего уровня.

## Минимальный пример

```python
import base64
pdf = base64.standard_b64encode(open("report.pdf", "rb").read()).decode()
message = client.messages.create(
    model="claude-opus-5-5", max_tokens=1024,
    messages=[{"role": "user", "content": [
        {"type": "document", "source": {"type": "base64", "media_type": "application/pdf", "data": pdf}},
        {"type": "text", "text": "Summarize this document."},
    ]}],
)
```

Документ идёт первым блоком, вопрос — вторым. Код проверен против локального мок-сервера (см. «Как проверялся код» в [базовой теории](basics.ru.md)).

## Когда применять и когда нет

| Задача | Выбор |
|---|---|
| Вопросы по PDF, отчёту, договору | блок `document` |
| Анализ скриншота, графика, фото | блок `image` |
| Один и тот же файл в нескольких запросах | Files API + `file_id` |
| Ответ со ссылками на источник | `citations: {enabled: true}` |
| Ответ строго JSON и цитаты | нельзя одновременно: выбрать одно |
| Сканы без текстового слоя | цитировать нельзя (только текст) |
| Таблицы Excel, документы Word | не поддерживаются в `document`: конвертировать в текст или PDF |

- ❌ Не пересылайте большой base64 в каждом ходе диалога: используйте `file_id`.
- ❌ Не принимайте `file_id` от конечных пользователей: файлы привязаны к рабочему пространству.
