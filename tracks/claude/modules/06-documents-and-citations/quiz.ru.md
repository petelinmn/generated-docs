# Квиз: документы и цитаты

🌐 **Русский** · [English](quiz.en.md)

> Сначала ответьте сами, потом откройте ответ. Метка показывает уровень вопроса: 🟢 [базовая](basics.ru.md) · 🟡 [продвинутая](advanced.ru.md) · 🔴 [экспертная](expert.ru.md).

## 1. 🟢 Каким блоком передают PDF?

- A) `image`
- B) `document`
- C) `file`
- D) `attachment`

<details><summary>Ответ</summary>

**B.** Источник — `base64`, `url` или `file` (`file_id`).
→ [Базовая теория](basics.ru.md#блок-document-и-источники)

</details>

## 2. 🟢 Где размещать документ относительно вопроса?

- A) После вопроса
- B) Перед текстом вопроса
- C) В `system`
- D) Не важно

<details><summary>Ответ</summary>

**B.** Рекомендация документации: документы и изображения до текста.
→ [Базовая теория](basics.ru.md#блок-document-и-источники)

</details>

## 3. 🟢 Как включить цитаты?

- A) `"citations": {"enabled": true}` на блоке `document`
- B) `citations=True` на уровне запроса
- C) Добавить в промпт «цитируй»
- D) Включить бета-заголовок

<details><summary>Ответ</summary>

**A.** Нужно включать на всех документах запроса или ни на одном.
→ [Базовая теория](basics.ru.md#цитаты)

</details>

## 4. 🟢 Какой тип у ответа с цитатами?

- A) Одна строка
- B) Список блоков `text`, у некоторых есть массив `citations`
- C) Словарь `{answer, sources}`
- D) Блок `citation`

<details><summary>Ответ</summary>

**B.** Склеивайте блоки, собирая ссылки из `citations`.
→ [Базовая теория](basics.ru.md#цитаты)

</details>

## 5. 🟡 Что выберете для PDF, который используется в двадцати запросах?

- A) Каждый раз base64
- B) Загрузить в Files API и ссылаться по `file_id`
- C) Вставлять текст в `system`
- D) URL без кэша

<details><summary>Ответ</summary>

**B.** Это экономит размер запросов; можно и кэшировать документ.
→ [Продвинутая теория](advanced.ru.md#files-api-в-диалогах)

</details>

## 6. 🟡 Чем `page_location` отличается от `char_location`?

- A) Ничем
- B) Первый — для PDF (страницы с единицы), второй — для текста (индексы символов с нуля)
- C) Первый — для изображений
- D) Второй — для PDF

<details><summary>Ответ</summary>

**B.** Концы диапазонов не включаются.
→ [Продвинутая теория](advanced.ru.md#виды-документов-и-цитат)

</details>

## 7. 🟡 Что произойдёт при цитатах и `output_config.format` в одном запросе?

- A) Всё сработает
- B) Запрос вернёт 400
- C) Цитаты отключатся
- D) Формат проигнорируется

<details><summary>Ответ</summary>

**B.** Решение — два шага: ответ с цитатами, затем извлечение структуры.
→ [Продвинутая теория](advanced.ru.md#несовместимости)

</details>

## 8. 🟡 Как посчитать токены изображения 1000×1000?

- A) 1000
- B) `⌈1000/28⌉ × ⌈1000/28⌉` = 1296
- C) 28
- D) 1000 × 1000

<details><summary>Ответ</summary>

**B.** Изображение считается патчами 28×28 пикселей.
→ [Продвинутая теория](advanced.ru.md#стоимость-в-токенах)

</details>

## 9. 🟡 Выберите все верные утверждения

- [ ] A) `cited_text` не считается выходными токенами
- [ ] B) Изображения можно цитировать
- [ ] C) `document_index` считается по всем документам запроса
- [ ] D) Файл в Files API можно переименовать

<details><summary>Ответ</summary>

**A, C.** B неверно: цитируется текст; D неверно: файлы неизменяемы.
→ [Эксперт](expert.ru.md#цитаты-структура)

</details>

## 10. 🔴 Найдите ошибку

> «Мы принимаем от пользователя `file_id` и подставляем в запрос — так удобнее».

<details><summary>Ответ</summary>

Файлы привязаны к рабочему пространству: принимать `file_id` от конечных пользователей нельзя (утечка и подмена). Храните идентификаторы на сервере.
→ [Подвох 6](expert.ru.md#6-файлы-привязаны-к-рабочему-пространству)

</details>

- A) Модель не читает сканы
- B) Цитируется только извлечённый текст; изображения цитировать нельзя, хотя модель «видит» страницу
- C) Лимит страниц
- D) Нужен бета-заголовок

<details><summary>Ответ</summary>

**B.** Сначала распознайте текст.
→ [Подвох 3](expert.ru.md#3-скан-без-текста)

</details>

</details>

## 13. 🔴 Открытый вопрос

Спроектируйте помощника, который отвечает по набору PDF с указанием страниц и возвращает ещё и структурированную сводку.

<details><summary>Ключевые мысли хорошего ответа</summary>

- PDF загружены в Files API (`file_id`), `cache_control` на документах; документы перед вопросом.
- Цитаты на всех документах; из `page_location` собираем номера страниц и проверяем `cited_text`.
- Структурированная сводка отдельным вторым запросом (цитаты несовместимы с `output_config.format`).
- Сканы — сначала текст; `file_id` только на сервере; лимиты страниц и размера.

</details>

→ [Продвинутая теория](advanced.ru.md)
