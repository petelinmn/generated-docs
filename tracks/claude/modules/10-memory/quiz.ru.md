# CLAUDE.md и память: квиз

🌐 **Русский** · [English](quiz.en.md)

> Сначала ответьте сами, затем раскройте ответ. 🟢 [базовый](basics.ru.md) · 🟡 [продвинутый](advanced.ru.md) · 🔴 [экспертный](expert.ru.md).

## 1. 🟢 Кто пишет автопамять?

- A) администратор
- B) git
- C) Claude
- D) вы вручную при установке

<details><summary>Ответ</summary>

**C.** Автопамять — это заметки, которые Claude сам делает по ходу работы. Администратор управляет managed-настройками, git ничего не пишет, вручную вы редактируете `CLAUDE.md`.
→ [Базовая теория](basics.ru.md)

</details>

## 2. 🟢 Какой файл не должен попадать в git?

- A) `CLAUDE.local.md`
- B) `CLAUDE.md`
- C) `.claude/rules/general.md`
- D) `AGENTS.md`

<details><summary>Ответ</summary>

**A.** `CLAUDE.local.md` — личные инструкции одного разработчика, поэтому его добавляют в `.gitignore`. Остальные три файла общие для команды и коммитятся.
→ [Базовая теория](basics.ru.md)

</details>

## 3. 🟢 Как надёжно запретить чтение `.env`?

- A) написать об этом в `CLAUDE.md`
- B) добавить в автопамять
- C) сказать в первом сообщении
- D) правило прав `deny`

<details><summary>Ответ</summary>

**D.** Только правило прав проверяется программой при вызове инструмента. Текст в `CLAUDE.md`, памяти или сообщении — пожелание модели без гарантии.
→ [Базовая теория](basics.ru.md)

</details>

## 4. 🟢 Какой ориентир размера `CLAUDE.md`?

- A) без ограничений
- B) меньше 200 строк
- C) меньше 20 строк
- D) до 25 МБ

<details><summary>Ответ</summary>

**B.** Ориентир — меньше 200 строк: длинный файл тратит контекст и соблюдается хуже. Сжимать до 20 строк не требуется, а 25 КБ — это порог загрузки `MEMORY.md`, не размер `CLAUDE.md`.
→ [Базовая теория](basics.ru.md)

</details>

## 5. 🟡 Когда загрузится правило с `paths: ["**/*.py"]`?

- A) после сжатия обязательно
- B) когда Claude откроет подходящий файл
- C) всегда при старте
- D) только по `/memory`

<details><summary>Ответ</summary>

**B.** Правило с `paths` загружается по требованию, когда Claude работает с подходящим файлом. При старте грузятся правила без `paths`; после сжатия оно не обязано вернуться само, и команда `/memory` для этого не нужна.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 6. 🟡 Что верно об импортах?

- [ ] A) в обратных кавычках не срабатывают
- [ ] B) не занимают контекст
- [ ] C) пути считаются от каталога запуска
- [ ] D) не больше четырёх переходов

<details><summary>Ответ</summary>

**A, D.** `@путь` внутри кода считается текстом, а вложенность импортов ограничена четырьмя переходами. Импортированное занимает контекст, как обычный текст, а относительные пути считаются от файла с импортом.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 7. 🟡 В репозитории есть `CLAUDE.md` и `AGENTS.md` (настройки по умолчанию):

- A) читается только `CLAUDE.md`
- B) читаются оба
- C) только `AGENTS.md`
- D) ни один

<details><summary>Ответ</summary>

**A.** При настройке по умолчанию `AGENTS.md` читается, только если нет `CLAUDE.md` и `CLAUDE.local.md`. Здесь `CLAUDE.md` есть, поэтому `AGENTS.md` пропускается.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 8. 🟡 Сколько из `MEMORY.md` грузится в начале?

- A) первые 20 строк
- B) ничего
- C) 200 строк или 25 КБ
- D) весь файл

<details><summary>Ответ</summary>

**C.** В начале сессии грузятся первые 200 строк `MEMORY.md` или 25 КБ — что наступит раньше. Остальное читается по мере надобности.
→ [Продвинутая теория](advanced.ru.md)

</details>

## 9. 🔴 Как `CLAUDE.md` попадает в запрос?

- A) заменяет системный промпт
- B) как инструмент
- C) как заголовок HTTP
- D) сообщением пользователя

<details><summary>Ответ</summary>

**D.** Содержимое передаётся сообщением после системного промпта, поэтому это контекст, а не жёсткая настройка. Системный промпт оно не заменяет, инструментом и заголовком не является.
→ [Экспертная теория](expert.ru.md)

</details>

## 10. 🔴 HTML-комментарий в `CLAUDE.md`:

- A) исполняется
- B) вырезается до отправки
- C) отправляется как есть
- D) вызывает ошибку

<details><summary>Ответ</summary>

**B.** Блочные HTML-комментарии удаляются перед отправкой — так оставляют заметки для людей без расхода токенов. Они не исполняются и ошибки не вызывают.
→ [Экспертная теория](expert.ru.md)

</details>

## 11. 🔴 Что загрузит `claude --bare`?

- A) только проектный
- B) все
- C) никакие из них
- D) только пользовательский

<details><summary>Ответ</summary>

**C.** `--bare` отключает автоматическую загрузку инструкций, и проектных, и пользовательских: в проверке не загрузилось ничего.
→ [Экспертная теория](expert.ru.md)

</details>

## 12. 🔴 Открытый вопрос: `CLAUDE.md` вырос до 900 строк, Claude пропускает правила. Что делать?

<details><summary>Ответ</summary>

Удалить очевидное и устаревшее, убрать противоречия; правила для частей кода вынести в `.claude/rules` с `paths`; редкие процедуры — в skills; обязательные запреты — в права и hooks; проверить `/context`.
→ [Продвинутая теория](advanced.ru.md)

</details>
