# Пользовательские хуки

🌐 **Русский** · [English](overview.en.md)

## Коротко

Пользовательский хук (custom hook) — это функция с именем на `use`, вызывающая другие хуки. Он позволяет компонентам переиспользовать логику с состоянием и эффектами: подписки, таймеры, хранилище, запросы. Каждый вызывающий компонент получает собственное состояние: хук делится логикой, а не данными.

## Ключевые идеи

- Имя начинается с `use` и заглавной буквы.
- Хуки вызывают только из компонентов и других хуков, на верхнем уровне.
- У каждого вызова свои состояние и эффекты.
- Тело выполняется при каждом рендере компонента.
- Возвращайте устойчивые значения, если от них могут зависеть.
- Действительно общие данные живут в хранилище, context или общем родителе.
- Функции, не вызывающей хуки, приставка не нужна.

## Минимальный пример

```tsx
export function useToggle(initial = false) {
  const [on, setOn] = useState(initial);
  const toggle = useCallback(() => setOn(v => !v), []);
  return [on, toggle] as const;
}
```

## Когда применять, а когда нет

- ✅ Одна и та же логика эффектов или состояния в нескольких компонентах.
- ✅ Скрыть детали API браузера или подписки.
- ❌ Обёртка над моментом жизненного цикла вроде «выполнить при монтировании».
- ❌ Чистые вычисления: достаточно обычной функции.
