## 6. 🟡 Найди ошибку

```tsx
items.map(item => (
  <>
    <dt key={item.id}>{item.term}</dt>
    <dd>{item.def}</dd>
  </>
))
```

<details><summary>Ответ</summary>

Ключ должен быть на фрагменте: `<Fragment key={item.id}>`.

→ [Продвинутая теория](advanced.ru.md)

</details>

## 12. 🔴 Открытый вопрос: у строк таблицы есть редактируемый комментарий, и после сортировки комментарии оказываются у других строк. Почему и как исправить?

<details><summary>Ключевые пункты ответа</summary>

- Ключи — индексы (позиции), поэтому состояние и поля остаются на месте.
- Взять устойчивый id из данных.
- Если комментарии должны переживать удаление строк, хранить их в родителе по id.

→ [Экспертная теория](expert.ru.md)

</details>
