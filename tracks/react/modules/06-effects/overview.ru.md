# Эффекты

🌐 **Русский** · [English](overview.en.md)

## Коротко

Эффект (effect) синхронизирует компонент с тем, что находится вне React: соединением, таймером, API браузера, запросом. Он выполняется после того, как React зафиксировал изменения на экране, и может вернуть функцию очистки, отменяющую сделанное. Многое из того, что кажется требующим эффекта, его не требует: значения, вычислимые из данных, и реакции на действия пользователя.

## Ключевые идеи

- Рендер должен оставаться чистым; побочные действия — в эффектах.
- Массив зависимостей говорит, на какие значения реагирует эффект.
- Очистка выполняется перед следующим запуском и при размонтировании.
- В разработке `StrictMode` выполняет установку и очистку лишний раз.
- Эффект видит значения того рендера, который его создал.
- Ответы могут приходить не по порядку: старые игнорируйте или отменяйте.
- Если значение вычислимо при рендере, эффект не нужен.

## Минимальный пример

```tsx
useEffect(() => {
  const connection = createConnection(room);
  connection.connect();
  return () => connection.disconnect();      // cleanup
}, [room]);                                   // run again when room changes
```

## Когда применять, а когда нет

- ✅ Подписки, таймеры, соединения, виджеты не на React.
- ✅ Загрузка данных, когда для этого нет фреймворка или библиотеки данных.
- ❌ Преобразование props или состояния для показа.
- ❌ Реакция на клик: делайте это в обработчике.
