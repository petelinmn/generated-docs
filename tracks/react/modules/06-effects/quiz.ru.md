## 6. 🟡 Что на экране через секунду?

```tsx
useEffect(() => {
  const id = setInterval(() => setN(n + 1), 100);
  return () => clearInterval(id);
}, []);
```

<details><summary>Ответ</summary>

`1`: обработчик помнит `n`, равное 0.

→ [Продвинутая теория](advanced.ru.md)

## 12. 🔴 Открытый вопрос: чат переподключается при каждой смене темы. Почему и как исправить?

<details><summary>Ключевые пункты ответа</summary>

- Эффект подключения читает `theme`, поэтому она зависимость.
- Вынести использование `theme` в `useEffectEvent`, оставив зависимостью только `room`.
- Не убирать `theme` из массива, заглушая линтер.

→ [Экспертная теория](expert.ru.md)

</details>
