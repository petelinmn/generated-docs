# Формы

🌐 **Русский** · [English](overview.en.md)

## Коротко

У поля формы уже есть собственное значение внутри браузера. В React вы решаете, кто им владеет. **Управляемое** (controlled) поле берёт значение из состояния, и источник истины — React. **Неуправляемое** (uncontrolled) хранит значение само, а вы читаете его, когда нужно, обычно через `FormData` при отправке.

## Ключевые идеи

- Управляемое: `value` (или `checked`) плюс `onChange`.
- Неуправляемое: `defaultValue` (или `defaultChecked`), читается при отправке.
- Поле не должно переходить из одного режима в другой.
- Значение поля — строка, даже для чисел.
- `FormData` собирает именованные включённые элементы; неотмеченных флажков в нём нет.
- Встроенная проверка браузера выполняется до вашего обработчика отправки.
- `useId` связывает подпись с полем.

## Минимальный пример

```tsx
function Upper() {
  const [v, setV] = useState('');
  return <input value={v} onChange={e => setV(e.target.value.toUpperCase())} />;
}
// typing "abc" shows "ABC"
```

## Когда применять, а когда нет

- ✅ Управляемые: проверка на лету, форматирование, зависимые поля, отключение кнопок.
- ✅ Неуправляемые: простые формы, читаемые только при отправке.
- ❌ Состояние для десятков полей, на которые вы не смотрите во время ввода.
- ❌ Проверка на клиенте как единственная защита: сервер обязан проверять тоже.
