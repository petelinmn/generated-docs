# Состояние и события

🌐 **Русский** · [English](overview.en.md)

## Коротко

Состояние (state) — это память компонента: данные, переживающие рендеры, изменение которых вызывает новый рендер. События — способ, которым действие пользователя доходит до вашего кода. Обычный цикл: происходит событие, обработчик задаёт состояние, React рендерит снова и обновляет страницу. Большинство сюрпризов — из одного правила: во время рендера состояние является неизменным снимком.

## Ключевые идеи

- Локальная переменная теряется между рендерами и не вызывает новый.
- `useState` возвращает текущее значение и функцию, запрашивающую новый рендер.
- В пределах одного рендера значение не меняется, даже сразу после установки.
- Несколько обновлений в обработчике применяются вместе.
- Передавайте функцию `x => x + 1`, когда следующее значение зависит от предыдущего.
- Не изменяйте объекты и массивы в состоянии; создавайте новые.
- Состояние принадлежит позиции в дереве; `key` или другой тип его сбрасывают.

## Минимальный пример

```tsx
function Counter() {
  const [n, setN] = useState(0);
  return <button onClick={() => setN(n + 1)}>{n}</button>;
}
```

## Когда применять, а когда нет

- ✅ Меняющиеся данные, которые нужно показывать: ввод, выбор, открыто или закрыто.
- ✅ Данные, которые компонент должен помнить между рендерами.
- ❌ Значения, вычислимые из props или другого состояния: вычисляйте при рендере.
- ❌ Значения, не влияющие на экран: для них есть ref.
